## Rebuild or verify

The central [editorial evidence bundle](editorial-supplement.zip) contains 912 issued multi-event and direct editing-operation calls, including every T115 process block, native onset ledgers, integer projected weights, per-call profiles and complete progression curves. Extract the archive and run `python verify.py`. It independently reconstructs each threshold and choice, checks branch short-circuiting, and computes paired operating times for four fresh processes per asset. SHA256 `7714901d9bd4992e2f5e5cac222f54ac1842b9a6be4f99281abfce9cdde95c07`, 604,817 bytes. [Packager](pack_editorial_supplement.py) · [Standalone verifier](verify_editorial.py)

For the earlier single-event work, extract [query-supplement.zip](query-supplement.zip) into an empty directory and run `python verify.py` for per-call verification of the short queries, long clicks and three-asset maximal-prefix comparison. It includes sanitized native event logs, individual timings, cache/repair diagnostics, audit receipts and experiment definitions. [Packager](pack_query_supplement.py) · [Verifier](verify_query_supplement.py). ## If the research becomes ready

SIGGRAPH 2027 uses one Technical Papers submission and considers all submissions for the journal outcome. A version of at most nine pages excluding references is also eligible for a conference proceedings outcome. These outcomes carry different publication venues. Before uploading, the human authors need to finalize authorship, verify scientific claims and AI disclosures, review the existing public prepublication and historical manuscript for the submission form, and check the anonymity and permissions of the deliverables, including a representative image. The working files have been published to the research branch. No entry has been created in the submission system.
