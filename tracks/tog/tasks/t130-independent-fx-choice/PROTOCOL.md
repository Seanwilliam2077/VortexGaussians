# One independent FX shot with two candidate edits

Registered 26 November 2026, before a participant brief or any candidate execution. The question is whether sharing a gas trajectory after two material states diverge can help an artist make an actual shot decision and continue the kept take in a second, naturally coupled solver. One artist and one chosen edit pair constitute one case.

## Shared simulation and matched ordinary control

Both paths receive the same admissible pre-edit checkpoint, compiled kernels, camera data and render caches. The ordinary solver may stop early when the artist's stated ordering permits it, share the same physical run across views, and continue a kept live take directly. Both must generate the same deliverable, including any requested continuation. For exact reuse, register the native state fields, pending cloth feedback, all gas-side inputs and clock/RNG checks identified in the [source gate](SOURCE_GATE.md). A full-state restore must pass a native successor check against an uninterrupted take; a render-only cache entry does not establish continuation. If native repeatability cannot support an exact comparison, record that boundary and do not convert it into an approximate result under the original claim.

Record separately the edit activation, the first actual difference in evolving cloth state, and the first failed gas-input check. A gas substep is eligible only while its effective inputs and complete starting gas state agree. Count savings separately for shared time before activation, a single scheduling lag, and sharing that survives a genuine material difference. A useful post-divergence window is one that saves work beyond the existing ordinary prefix and lag. If a changed emitter or cloth feedback closes the window immediately, preserve a zero-length or lag-only outcome. Never alter the edit to manufacture a longer prefix after seeing its result.

## What would count as evidence

1. **Correctness and usability.** Compare each candidate's requested physical state and native image against ordinary replay, and compare the first native successor of the kept take, or its longer continuation when requested. Separately record the artist's actual keep/reject choice, followed by their judgment of randomly ordered ordinary native playbacks of both alternatives with method labels, filenames and timings hidden. Multiple acceptable takes, neither, and a changed decision are valid observations.
2. **Delivered wall time.** Measure from issuing the edit to the promised return, including guard and synchronization, both cloth trajectories when needed, materialization and restore, rendering, readback and the requested continuation. Separate the artist's viewing time. Report shared preparation time, first-call latency and warm calls. Before opening outcomes fix the resource envelope from the selected shot and preflight. Use three fresh serial processes with alternating method order, one untimed correctness audit and one warmup plus four measured pairs per process. Show raw pairs and each process median. A favorable warm result requires the same direction in all three process medians; report effect sizes either way. A saved gas step alone has no latency interpretation.
3. **Scope.** Report the signed result for this independent case. An expensive guard, a zero-length window, different playback judgments or a faster ordinary path are informative. Researcher-selected inputs, a neutral device test, and an artist-validated shot are tracked separately. No new paper score is assigned without a new independent review.

The unedited preflight has its own fixed resource limit under [preflight](preflight/); it does not consume or open an experimental arm. Candidate timing and playback await a real brief and a viable native output path.

For the continuation audit, read the coupling-grid bytes and ready flag immediately after restoring the parent, **before** issuing the successor update. Use an independent engine or explicitly invalidate residual GPU buffers before restore. The neutral fixture uses one live engine and its recorded grid differs between checkpoint and successor. Endpoint agreement after that successor can hide an incorrect input on the first resumed substep. Include the cost of preserving or rebuilding this feedback in any timed reuse implementation.
