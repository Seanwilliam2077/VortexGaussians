# Unheated native readback and checkpoint preflight

This check used an empty Blackbody project, one default fabric and zero emitters. Neither a T130 artist brief nor an edited take was opened. Final-mode grid size was 16 × 32 × 16 with 1,470 cloth vertices. The dedicated NVIDIA GeForce RTX 5070 Laptop GPU ran through D3D12. The pinned checkout was `e2ac951dbfabc6060073943e4c344439ac5f4555`. The temporary runtime had Python 3.12.14, wgpu 0.32.0, NumPy 2.3.5, rendercanvas 2.7.2 and MuJoCo 3.3.7. [Original budget and inputs](CONTRACT.md) · [Admitted adapter and dependency hashes](../../t126-external-curtain-runtime/README.md)

The native disk cache saved frame 1. Its coupling grid was marked ready and contained 324 nonzero words out of 13,312. All fabric vertices measured 300 K and zero were burning. Uninterrupted and same-engine resumed frame 2 agreed in all checked gas checkpoint fields (velocity, scalar texture, pressure and clocks), native cloth checkpoint fields, the coupling-grid bytes and ready flag. The first and second runs both passed this output check.

The parent grid hash (`c7650445…`) differs from the ordinary successor grid hash (`0dd553e1…`). The same GPU object stayed alive during reset. Native cloth reset marks the cloth unplaced, while checkpoint load restores its saved vertex fields and marks it placed again. The serialized cloth state omits the feedback grid and ready flag. Residual buffers from the already-run successor could therefore affect the resumed input. These receipts verify the observed successor on one unheated fixture. They do not establish exact restoration into a fresh engine or continuation under burning-cloth feedback. The first worker returned from native fire rendering but the added `on_submitted_work_done_sync()` diagnostic raised a Python callback-signature TypeError before either pixel read. Worker wall time was 85.79 s. The second, separately registered worker uses the original native synchronous texture read as the completion boundary. A draw call returning on the host and finite pixel bytes reaching the CPU are recorded separately. [First result and failure](evidence/PREFLIGHT.json) · [Original trace](evidence/PHASES.ndjson) · [Single recovery contract](READBACK_RECOVERY.md)

**Native emission reached the CPU.** The recovery entered fire rendering at 67.372 s, returned at 68.219 s and completed emission readback at 68.221 s. The 320 × 180 × 4 half-precision texture was finite. Every RGB component was zero on this no-source fixture. The compressed native bytes and array digest are independently checkable. [Lossless emission](native-readback/fire.npz) · [Field and image receipts](native-readback/PREFLIGHT.json)

**The final composite remains unqualified.** The worker entered composite mode at 68.227 s. The volume-light call returned. At 68.234 s the native cold-pipeline notification identified `stage.wgsl`; no subsequent host phase returned and no composite bytes were stored. The outer worker raised its configured 360 s timeout, but the recorded elapsed wall time was **7,670.52 s**. Thus the actual wall limit was exceeded. There is no host residency or GPU timing trace across that gap and the reason for the discrepancy is unknown. No duration can be assigned to shader compilation from these data. Earlier T126 had coarser instrumentation and its last phase cannot be retrospectively attributed to this stage. The recovery budget is consumed. The experiment source is [qualify.py](qualify.py). To verify the distributed numerical observations, run `python verify.py` with NumPy, without importing the graphics driver. A local run requires the previously pinned Blackbody checkout, the recorded temporary runtime on PYTHONPATH, an unused output directory and the admitted GPU. The exact invocation is `python qualify.py --source SOURCE --out FRESH_DIRECTORY --native-read-fence`. The preflight measures plumbing on an unheated fixture; it contains no artist decision, treatment comparison or transfer-speed evidence.
