# Static camera guide

[framing.png](framing.png) is an optional neutral reference for a prospective shot. It depicts the two released rest meshes and the rail in the original camera. Both cloth panels use identical illustration colors. The horizontal and vertical scales refer to the full frame. This drawing contains no simulated frame, dynamic state, fire, source photography or candidate parameter labels. The project camera includes the actual anchor and 16:9 aspect. The solver's preroll would move the cloth, so the reference is a layout guide, not the first frame of a take.

The [builder](make_guide.py) calls the pinned Blackbody procedural panel, placement, camera and point-projection routines and checks camera rays at three landmarks per cloth. The two meshes have 1,353 vertices apiece. In the 1,024 × 576 inner viewport the first occupies (384.56, 174.86) to (505.71, 349.44) and the second (518.30, 174.86) to (639.23, 349.44). Use the existing T124 dependencies on the Python path and run `python make_guide.py --source PINNED_BLACKBODY_CHECKOUT`. It imports the scene and mesh definitions without constructing an engine or requesting a GPU. The distributed PNG has SHA-256 `45c2fc51b509bcac348a9f6d4b790015ed4619c09d17c80f8ec83bdf7a21308f`.
