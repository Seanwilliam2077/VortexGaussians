| 已读入口 | 实际路径 | 对 T15-C 的意义 |
|---|---|---|
| `volprim_rf` | 在射线峰值处求 Gaussian density，以 opacity 得到 alpha，逐 primitive 累积 SH emission；有 alpha clamp、throughput/depth 截断及默认 sRGB 转换。 | 没有沿这条路径调用解析密度积分；不能称为连续高斯 extinction 的有色重叠积分，也不能自动等同论文中的某个公式。 |

| `common.py` 的积分与遍历 | 包含 Gaussian 段积分、重叠集合和分段遍历。 | 工具函数存在不等于所选入口计算目标积分；可见重复扫描结构不等于已测到性能瓶颈。 |
