# T127 · Does visible gas support the woodpile brush choice?

Frozen on 25 November 2026 before any T127 native image was captured or viewed. This test reuses the two T109 interventions, seed 53, camera IDs 0 and 124 and the common frame-180 parent. The investigator-defined shot asks whether the rendered gas changes the display over at least a quarter of the projected shell mass at +90. The predicted per-arm outcomes are light fails and full passes in camera 0, both fail in camera 124. Compare each of the four Booleans directly with this prediction. The preference rule takes light first, then full, then neither. Report +44 for both arms and views as a descriptive intermediate sample. These two snapshots cannot give the first visible frame. No threshold, region, camera, time or arm is chosen with access to these images.

**Images.** Use the 940 × 528 native opaque RGB display composite at the fixed camera. Its paired control has the same physical state, camera, wood color, char, glow, occlusion and fixed display settings. It suppresses only the gas primitive draw. Both are saved with the camera's top row first and the same viewport. Require PNG RGB or opaque RGBA and the exact dimensions. The brush labels in the filenames are `light` and `full`. For each camera and time, suffix `full` is ordinary native rendering, suffix `wood` is its draw-only control. Private files follow `{brush}-c{camera}-h{steps}-{full|wood}.png`.

**Pixel test.** Read original display bytes with no color profile conversion, relighting or gamma transform. Downsample each image to 470 × 264 by the arithmetic mean of its four corresponding display pixels in each channel. Keep the unrounded average. Mark a pixel if the maximum absolute difference across RGB between the two means is at least 16 byte levels. This can be implemented exactly by comparing the two 2 × 2 integer channel sums to a threshold of 64. Differences can include both lighter and darker gas composites. The threshold is an operational definition chosen for this test. No perceptual calibration or creator evaluation is available.

**Weight.** Reconstruct the eligible static T109 shell (2,371 sites in these two branches) after excluding both brushes and previously lit sites. Reuse T107's depth-ordered alpha contribution raster for all 34,687 fitted Gaussians. All foreground sites attenuate transmission. At each pixel sum only eligible sites' contributions to obtain a floating shell weight. Divide the sum of those weights over marked pixels by their sum over the entire image. A value of at least 0.25 passes. Independent raster checks must match T109's archived floating denominator within relative error 3e-12, individual site weights within the T109 figure tolerance, and the rounded sum per site must exactly reproduce 282,825,750 and 829,199,132 micro-pixels. The mass denominator in the new pixel score stays floating. **Scope and stopping.** The readout measures visible impact of all gas over the original projected shell, including gas arriving from elsewhere. It cannot assign a flame pixel to a specific ignited material site, detect a flammable material through opaque smoke, or validate a human preference. Use all eight pairs and preserve mismatches. Withhold the comparison if source hashes, state/camera registration, fixed dimensions, opaque alpha, or native render invariance fail. Publish scalar numerators, denominators, counts, decisions and source/image hashes. Source appearance and native image pairs stay local. No alternate threshold or rendering rescue is part of this test.

**Reproduction.** From this directory run `python score.py --source PATH_TO_REGISTERED_INPUT` for the image-independent denominator check. With the capture integrity checks satisfied, pass `--frames PRIVATE_CAPTURE_DIRECTORY` to compute all eight comparisons. The command writes JSON to standard output. The experiment's capture owner archives the numerical output alongside the run receipt.
