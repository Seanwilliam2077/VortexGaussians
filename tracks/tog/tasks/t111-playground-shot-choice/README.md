# A complete editing choice on a second fitted shot

Two candidate brushes fork from the same frame-180 Playground parent. The action tries the light brush first. It tries the full brush only if the requested camera still falls short of one-quarter burned foreground-matte coverage by 90 steps. The calibrated cameras, parent seed, preference, deadline and timing budget were fixed before the two native futures were inspected. The two cameras shared the same physical simulation when requested together. [Prospective shot definition](PROTOCOL.md) · [Timing contract](TIMING_PROTOCOL.md)

The light brush qualified at +53 from camera 0 and +76 from camera 153. The ordinary baseline with a retained recipient index took 401.1 ms in camera 0 and 622.8 ms for both views. Exact material repair took 459.0 and 634.1 ms respectively. Both restored the starting editor state. All 36 issued decisions and every audited 90-step curve agreed with the independent reference. This transfer establishes correct choices on a second scene, with an ordinary win on warm median latency.
