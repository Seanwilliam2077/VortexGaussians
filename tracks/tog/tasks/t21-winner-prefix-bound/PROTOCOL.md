## Single candidate, fixed in advance

Use the original stable mean order. Indices i<j below denote ranks in that order, not original input indices. All clipped masses tau, pair caps B, colors, G, sorted RGB and reference RGB come from the sealed T18 result.

For each rank i, P_i=exp(-sum_{k<i} tau_k). For each inherited B in {simple,Jensen}, C_ij=P_i B_ij. For channel q define

    U_q = sum_{i<j} max(c_jq-c_iq,0) C_ij
    V_q = sum_{i<j} max(c_iq-c_jq,0) C_ij
    lower_q = -min(G_q,V_q)
    upper_q =  min(G_q,U_q)
    E_new,q = max(-lower_q,upper_q) = min(G_q,max(U_q,V_q)).

The interval encloses Delta=L_exact-L_sorted in real arithmetic. The output color stays the saved original sorted RGB. No midpoint correction, shifted color-hull intersection, row-cap optimization, omitted suffix model, hierarchy, or additional candidate is allowed. Simple and Jensen are the two inherited pair caps, not a post-result choice; Jensen alone determines admission.
