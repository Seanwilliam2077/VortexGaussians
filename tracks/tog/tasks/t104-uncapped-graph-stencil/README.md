# Regional dependence under full graph service

The existing native material solver has a fair full-graph configuration: raise the donor budget to the repository's one-million cap and every old or newly burning site deposits graph heat in native order each step. We tested whether regional simulation stays exact when new off-region donors can no longer be ignored under the old first-1,400 assumption. On Playground, a different condition worked: the receiver's whole graph component was separable, and the gas-emitter sequence was independently certified. New local donors entered and affected the precise result. The component solver improved both fresh-index comparisons and lost both reusable-anchor comparisons. This evidence supports conditional exactness; the benefit depends on which ordinary index is available. ## Prospective changed-policy results

The graph cap changed from frame zero. We retained every physical point, original first and second strokes, second click at frame 180, and 60-step lookahead. Every timing repeat started from the same state. Independent native trajectories supplied the labels. Four methods each executed one warmup plus four measured calls on each of four scene/order pairs, for 64 measured calls and 16 warmups. All returned the correct Boolean, exact first frame and a valid first-frame witness when positive. The native state after rollback matched its pre-click marker. Completed fresh, newly built anchor and warm-anchor backend runs agreed with native on all material, frontier, ordered particle and RNG values across eight steps after each of the four clicked inputs.

The whole material graph fits in one component on both Firewoods and Dead Tree Trunk. Playground has four components. Its A→B and B→A shells touch 30,459 and 9,810 of 80,023 sites, respectively. In both prospective Playground runs the old emitter population and cursor certified all 60 steps. The answers came after two; neither query needed a restart. Under the original capped operator these same click centers produced first events after 24 and 15 steps. The changed-policy outcome is computed independently.

On Playground A→B, 2,058 in-component donors were already beyond global rank 1,400 at the second click. The full two-frame audit recorded another 1,819 local ignitions. On B→A the corresponding counts were 1,620 and 987. Across both first-event intervals, the region-matched native comparison checked 402,690 material entries, ordered local frontiers, gas/RNG/cursor and 7,333 ordered particle states. The audit continued the complete crossing frame after observing its first witness, so its counts include other sites crossing on that same frame. The timed query returns immediately on its first witness. [Playground native frames and raw timings](evidence/playground/CAPTURE.json)

The cold component-index build cost 717.6 and 547.5 ms on the two Playground orders, paid by the first component-fresh calls (887.8 and 653.4 ms total). The persisted typed-array component labels use 320,092 bytes, with additional temporary spatial and BFS storage to build them. Compared at matched cache availability, component-fresh reduced warm delivered time by 15.7% and 52.7%; component-anchor took 4.0% and 12.9% longer than ordinary active-anchor. The shorter +2 horizons leave little time to amortize reusable topology or graph-row setup. The fair-schedule result includes two genuinely informative edits from one fitted scene, zero nonempty censored queries and zero prospective guard expirations. An artistic brief, broader physical settings and independent artist use were outside this measurement.
