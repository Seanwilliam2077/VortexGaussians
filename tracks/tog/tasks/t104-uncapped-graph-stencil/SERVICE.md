# Which existing service rules transfer?

The native graph loop visits the first `min(burning.length,spreadFrontierCap)` entries, in their current order. New sites append after the threshold scan. Native code has no cursor for graph donors. Its cyclic cursor governs the later material-to-gas emitter offers. At cap 1,400 this distinction is measurable. The T42 second click appended burners at ranks 3,374–3,661; while older entries survived, the new burners received no outgoing graph service. The elapsed-clock option advances all burners' fuel but keeps that same limited graph service. T104 changes only the graph cap to the one-million value already used in the repository's P2 control suite. All original material sites fit under it on all three scenes. Every old and newly ignited donor now contributes in native order at every step. A proof that old burners survive and emitter offers are known can no longer discard arbitrary new off-region graph donors. One can still discard *other graph components* if the emission sequence is separately certified. Protected components must execute newly ignited material, including all newly active donors, as well as their fuel, glow, charring and ordered graph contributions. All gas continues globally. This changes a service policy within the existing material/gas solver. [Existing full-neighbor cap](../../../../research/p2-design.mjs)

P2's separate area-measure policy weights graph transport by each donor's authored area and uses compensated accumulation before a single binary32 recipient store. More importantly, total burning area generates fractional emission credits, and emission locations are random weighted draws over the complete active population. A missing new burner can change both number and location of offers before a cyclic boundary. The old-cursor guard does not cover this case. Ordinary fitted PLY files do not supply the required material area. An experiment that invented these areas would address a different asset contract. P1's alternative recycling admission can replace a cold particle in a full layer, but the donor scheduler remains fixed; matching the full gas would be needed to preserve slot, RNG and carrier identity. Layered VIC is another existing gas solver with coarse fields and per-layer Eulerian grids. The current VPM branch copy leaves those grids shared and cannot be reused as a VIC benchmark. VIC also retains the same material scheduler. Under complete graph service the bare H-scan causal graph extends H−1 material hops. At each stage the native heat deposition from a new donor can change a neighbor's *next* ignition scan. The initial geometric dependency of an arbitrary queried unlit subset lies in the connected components containing it. This is a geometric upper domain for possible dependencies, independent of actual fuel and heat. It may greatly overcount the real dependency set.

Firewoods and Dead Tree Trunk are each one connected material component. Diameters there are bounded by twice the eccentricity of site 0 (24 and 42 hops). Thus *any* surviving eligible shell site on those scenes reaches the full component by H=60 under unrestricted geometric hops. Playground has components of sizes 30,459, 39,736, 9,810 and 18. Each of its two selected shells lies within just one component. The two edit arms passing the geometry gate both come from this fitted scene. All shell IDs match the original loaded geometry. A mutable spatial-hash BFS removes already discovered sites to avoid allocating a dense adjacency list. Source positions and graph radius are unchanged.
