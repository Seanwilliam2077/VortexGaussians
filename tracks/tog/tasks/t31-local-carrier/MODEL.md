# Authored continuous P3 lift, version1

For each existing shared3d render particle, retain its world position mu, temperature T, density parameter d and existing optical weight w (explicit particle weight if supplied; otherwise1). Let R=.045, h=R/sqrt(6), k=max(0,w*.2*d). Define isotropic extinction

    sigma_i(x) = k_i / (sqrt(2*pi)*h) * exp(-||x-mu_i||^2/(2*h^2)).

Sigma has inverse-world-length units; total integrated3D strength is2*pi*k*h^2, NOT physical mass. For a unit ray x=o+t*v, z_i=dot(mu_i-o,v), r_i^2=||mu_i-o||^2-z_i^2 (clamp only roundoff-negative values), its full-line optical mass is q_i=k_i*exp(-r_i^2/(2*h^2)). On [a,b] the mass is q_i*[Phi((b-z_i)/h)-Phi((a-z_i)/h)]. Stable interval-tail evaluation is necessary in a numerical adapter; blindly subtracting two rounded CDFs is not an accuracy guarantee.

Original P3 uses g(rho)=(exp(-3*rho^2/R^2)-exp(-3))/(1-exp(-3)), rho<R, and billboard alpha1-exp(-k*g). The new field removes truncation and pedestal subtraction, replaces perspective billboard-UV distance by true ray-perpendicular distance, and integrates overlapping continuous media. It is not an image-preserving conversion. R is the original billboard half-axis, not its standard deviation. Normalization is shared by ordinary and future candidate methods, with no fitted scale, contrast, thinning or selective particles.

Color is view-independent linear RGB. Clamp t=T into[0,1], start at c0=(.05,.012,0), and successively mix with c1=(.6,.05,.012), c2=(1,.32,.04), c3=(1,.72,.22), c4=(1,.96,.86), using smoothstep intervals(0,.28),(.22,.5),(.46,.74),(.7,1). Fire color is that ramp times emis*(.25+.85*t). Smoke color is mix((.02,.02,.026),(.17,.17,.19),clamp(d,0,1)). The captured original mode/emis select the formula; no mode change. HDR values above1 are retained. This formula is evaluated in binary64 for the new field; the original shader executes different floating-point arithmetic.

Target radiance on a finite ray is C=integral_a^b exp(-integral_a^t sum_i sigma_i(o+s*v)ds) * sum_i sigma_i(o+t*v)c_i dt with black background. Alpha=1-exp(-sum_i finite_mass_i). Emission here is proportional to extinction; this is not a combustion/blackbody physical claim. No bloom, exposure, gamma, depth sprites or display composite enters the target.

Camera is reconstructed from captured params: target(0,1.05,0), eye=target+camDist*(cos(camElev)*sin(yaw*pi),sin(camElev),cos(camElev)*cos(yaw*pi)). Orbit is off. Back=normalize(eye-target), right=normalize((back.z,0,-back.x)), up=back cross right, forward=-back. FOV is vertical radians. For top-down row j and column i, both zero-based, pixel-center direction is normalize(forward + right*(2*(i+.5)/256-1)*(256/192)*tan(fov/2) + up*(1-2*(j+.5)/192)*tan(fov/2)). a=.05/dot(v,forward), b=50/dot(v,forward). These are projection-plane clips converted into ray distance, not constant ray distances. Both captured states use front yaw0, oblique yaw.7 and side yaw1.4; three views of ONE simulation are not three scenes.

Existing ordinary scalar Gaussian-aware GL integration in T22 evaluates the same1D model once this conversion is provided, but no full-frame adapter, acceleration structure, HDR error accounting or execution path is qualified by T31. Old normalized-color guarantees cannot silently be reused on these HDR colors. A future truncation/culling budget must multiply omitted optical mass by a safe radiance range that includes downstream emission/background; omitted extinction affects retained downstream particles too. Retain all particles in the carrier regardless of eventual visibility. Do not use original splat as the continuous-model truth.
