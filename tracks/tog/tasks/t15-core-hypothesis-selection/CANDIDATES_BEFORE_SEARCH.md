# Three fixed researcher-authored operations before search

28 October 2026. These proposals do not assert unmet production demand or literature novelty. None is a new example for the old image-protection solver or observation-ambiguity search. Only the operation is fixed; inspection must identify ordinary solutions rather than protect the proposed mechanism.

## A — Transfer a known physical smoke state between Gaussian particles and a grid

- **Input / operation / output:** known nonnegative volumetric extinction or smoke mass carried by anisotropic Gaussian particles, with explicitly specified mass and affine velocity; transfer to a simulation grid and back under changing resolution, then deliver a renderable and continuable state. Image-fitted 3DGS opacity is not assumed to be physical density. The practical question is whether representation changes can avoid artificial mass/momentum and visible extinction jumps.
- **Mechanism conjecture:** use Gaussian-support integrals and constrained low-order moments jointly when splitting/merging and depositing particles, so a bounded-budget representation change preserves the conserved quantities and optical-depth accuracy needed by continuation. Standard moment matching may already solve this; adding an appearance penalty is not a mechanism.
- **Strong ordinary baseline:** conservative deposition/resampling and affine particle-in-cell transfers, with the same kernels, degrees of freedom, resolution, physical parameters and reconstruction budget. Count support integration, split/merge, any constraint solve and render/continuation verification.
- **Minimal input route:** explicitly authored one-/two-Gaussian density and affine flow, followed only if justified by a known simulation snapshot. This permits analytic integral checks without claiming captured-scene calibration or a creator study.
- **First rejection condition:** existing conservative/affine transfer already provides the requested guarantees, or the optical condition is just ordinary integral-preserving resampling plus increased sampling. If the proposed joint requirement is incompatible at fixed degrees of freedom, do not hide the tradeoff by giving only the candidate extra particles.

## B — Reproject flow after edited solid geometry changes fluid connectivity

- **Input / operation / output:** an explicitly defined grid flow and solid boundary, then open/close a passage or relocate a barrier; deliver a valid pressure projection on the edited domain. Geometry and velocity must satisfy the declared incompressible model; a sealed shrinking volume is not an admissible incompressible test by fiat.
- **Mechanism conjecture:** update component/near-component coarse constraints when connectivity changes, so pressure iteration does not retain obsolete nullspace structure and avoids rebuilding unaffected solver work. The proposed opportunity is a topology-aware coarse solve under repeated geometry edits, not image-protection caching.
- **Strong ordinary baseline:** a rebuilt robust geometric/algebraic multigrid or domain-decomposed pressure solve with component handling, plus ordinary warm starts/reuse where valid. All topology detection, hierarchy setup/update, solve and divergence validation count; no baseline is forced to keep an invalid preconditioner.
- **Minimal input route:** researcher-authored connected/disconnected chambers and a moving/opening passage with known compatibility conditions. It tests projection algebra only, not the original periodic smoke core or a production latency requirement.
- **First rejection condition:** established multigrid/topology treatment already covers this mechanism, or the whole-cost advantage requires denying ordinary solvers the same component information/reuse. Component detection or mean-pressure fixing alone is not a new contribution.

## C — Composite overlapping emitting/absorbing Gaussian volumes with a bounded pixel error

- **Input / operation / output:** explicitly specified volumetric Gaussian extinction and bounded emission/color, a camera ray and opaque occlusion depth; integrate the participating volume under camera motion, including overlap. Deliver the declared emission-absorption pixel integral and an error account. Do not claim this model is identical to learned screen-space splat compositing or calibrated fire.
- **Mechanism conjecture:** analytic cumulative Gaussian optical depth plus conservative interval bounds on colored emission could let a ray choose subdivision or terminate while certifying pixel error; reuse support bounds across ray tiles only if they remain valid. The question is whether a Gaussian-specific bound can be materially tighter/cheaper than ordinary adaptive quadrature, not whether a generic quadrature tolerance can be displayed.
- **Strong ordinary baseline:** exact same continuous volume integrated by high-accuracy ray marching/adaptive quadrature; compare existing ray-based Gaussian methods under their actual optical model. A fast surface/sorted-alpha renderer with different semantics is only a contextual comparison. Count preprocessing, culling, bound evaluation and total samples at equal error.
- **Minimal input route:** two overlapping differently colored Gaussians with prescribed positive-definite covariances, extinction and occlusion depth; analytic monochrome limits supply a qualification check. No captured opacity-to-density conversion is needed and no new simulation task is invented.
- **First rejection condition:** existing Gaussian volume integration already supplies the operation/bounds, the proposed bound is just standard validated quadrature with no distinct tightening, or tighter bounds cost at least the ordinary integration. No speed or novelty is inferred from a paper's silence about certification.

Each surviving source-level question must name the remaining mechanism difference and the result that would stop it before implementation. Inputs above are qualification possibilities, not executed fixtures or demonstrated application value.
