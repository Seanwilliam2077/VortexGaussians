## Decision before T81 execution

Retain at most one subsequent mechanism question: **when a meaningful capacity/cost conflict actually exists, can controlling interaction response after short transport preserve later heat exchange or ignition more efficiently than instantaneous moment/rate fitting?** Ordinary spatial bins, moment/rate-constrained NNLS and warm starts must be allowed. The proposed horizon, response queries, weight meaning and total preparation/rollout cost must be explicit. “Add rate constraints” and “combine bins with NNLS” are already covered and are not the proposed novelty.

This hypothesis is conditional. The [independent source audit](MECHANISM_AUDIT.md) identifies a missing native weight contract: temperature is intensive, density enters nonlinear rendering, there is no multiplicity field, and flame heating uses index-dependent sampling. A generic shared reweighting changes the operator before any transport effect. Resolve that issue before numerical implementation. If an ordinary method resolves the task, or a fair weighted operator cannot be stated, do not queue a compression run to manufacture progress.
