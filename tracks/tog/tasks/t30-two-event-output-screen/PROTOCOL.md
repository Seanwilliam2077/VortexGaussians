## One operator and a cheaper early rejection

For the unchanged finite Gaussian model, let `tau_i` be clipped masses, `tau=sum tau_i`, `p0=exp(-tau)`, and `p3=Pr[Poisson(tau)>=3]`. Zero events return background; one event contributes `p0 sum_i tau_i c_i`. Exactly two events contribute `p0 M2`, where

```text
M2 = sum_i c_i tau_i^2/2
   + sum_(i<j) [ c_i (tau_i tau_j-I_ij) + c_j I_ij ].
I_ij = integral_a^b s_i(t) A_j(t) dt.
```

The finite pair interval is `L_ij=max(0,tau_i tau_j-U_ji) <= I_ij <= U_ij`, with `U_ij=min(tau_i tau_j,I_full_ij)` and the reverse upper obtained using the complementary full-line Gaussian ordering probability and **full-line** weights. Use the same pair midpoint in all channels to obtain `M2_hat`. For the uncomputed event count >=3, use the per-channel input-color box center `m=(c_min+c_max)/2`. Proposed output and a real-arithmetic radius are

```text
L_hat = p0 background + p0 sum_i tau_i c_i + p0 M2_hat + p3 m
radius = p0/2 sum_(i<j) abs(c_j-c_i)(U_ij-L_ij)
       + p3 (c_max-c_min)/2.
```

The box center need not lie in the common RGB convex hull. A small `p3=O(tau^3)` does not make the complete radius third order: uncertain clipped pair moments can contribute O(tau^2). `U` or the old saturated pair-probability bounds cannot be silently substituted for a signed correction. This construction is exactly a low-order expansion of `exp(tau-A(t))` under the original integral, plus a bounded residual; no independent novelty is presumed. Gaussian pair integration is additional information beyond a single optical-mass cell mixture, but all its acquisition and O(N^2) pair work must be paid in any later comparison.

Every declared radius is at least `p3*max_channel_color_range/2`. If that floor exceeds the unchanged epsilon, this **specific certificate** cannot accept even with exact pair moments. This does not lower-bound true output error or disqualify different tail treatments. Apply this inexpensive filter first; do not compute pair moments, outputs or corrected RGB in T30.

A further ordinary O(N) comparator keeps the exact one-event and same-label two-event terms, then encloses all cross-label two-event and higher-count terms in the same color box. Its radius is `[1-p0*(1+tau+sum_i tau_i^2/2)]*range/2`, with a corresponding midpoint output. It needs no pair integral. This comparator was identified during independent conceptual review before execution. It is required in any later output screen; T30 does not compute its output or label a survivor as an advantage over it.
