# Why sitewise temporal evaluation recovers the coupled branch

This statement applies to one T100-certified block inside T108 or T111, under the pinned legacy measure, elapsed fuel clocks, fixed unit-scale geometry and VPM gas. The prefix proof has already fixed the capped graph donor sequence throughout the block and the old emitter services before any reconstruction. Global gas, RNG, hot carrier positions/temperatures and the per-frame emitter cursor were advanced natively. A material recovery cannot move any of these data. At block start, old donors survive to the end. Cold-to-burning transitions are monotone; new graph donors only append outside the saturated graph cap.

Form, for each initially cold material recipient, its finite list of graph heat increments in native donor order. A T102 row may exclude a site already noncold at block start. Permanent noncold states render such a site ineligible for all future graph deposits. The cold index retained in a pre-click anchor is a superset of valid recipients on this branch; any stale receivers are removed by the block-start state check. Each donor contributes to each site at most once. Internal neighbor enumeration order for *different* recipients does not affect their values.

For a single site in a frame, first add all native sampled hot carriers whose compact supports intersect that site, in precisely their recorded order, rounding to binary32 after each addition. If heat is positive, store the rounded decay and test ignition against the same threshold and fuel. If it remains cold, add the per-donor graph increments, in order with all intermediate binary32 rounding preserved. The graph influence on this site's ignition is first observable at the next threshold scan. The state of any other recipient does not change any of these inputs within the existing certificate. Existing burning and charred points with positive heat continue to decay.

The implementation streams flame samples chronologically. A site keeps an integer count of its already completed frames. Immediately before the next flame deposit, it completes its own intervening material updates. Multiple samples from one frame remain in native order and see no intervening decay. The final pass completes every site's remaining local history. Zero heat with no graph input can remain exactly zero between sampled contacts. Ignited sites leave the cold set before graph heat is applied there. Required fuel, glow and char changes start on the ignition frame, or at the start for an old burner. Equal initial values and equal elapsed step counts produce identical binary32 recurrence values. The implementation memoizes these scalar recurrences; it retains the original rounded recurrence on its first evaluation and the ordinary terminal zero/one clamps. An expired new burner does not rejoin the frontier.

Finally, group new surviving sites by their first threshold frame. Scan sites in ascending native ID when filling each bucket. Concatenating to the old frontier in chronological bucket order therefore reproduces the original inter-frame and within-frame frontier order. Set the last recorded emission cursor. The resulting complete material can take the next coupled step using the global gas that is already at the block end. This proof does not need a continuum approximation or a second simulation seed. A changing graph prefix, area-weighted global emitter draw, nonmonotone eligibility, or scene interaction during the block requires a different proof.

This factorization preserves numeric stores and causality; its efficiency still depends on how often the hot source samples intersect receivers. Transposing the graph offers little time savings when donor edges are rare and chamber samples repeatedly visit large neighborhoods. The experiments report those counts and real click-to-answer delivery for dense, sparse and sitewise reconstructions of the same branches.
