# Can an editor certify that ignition stays inside a brush?

Across 18 queries, the weighted heat bound gave **zero complete regional answers**. Regional replay observed ignition in 10 windows and no ignition in eight. All eight negative answers required replay to the end of the window. All 10 positives required replay through the first ignition. The weighted method correctly excluded more individual sites than either comparison. The remaining uncertain sites determined the cost of this authoring query. ## Cost interpretation

Exact native replay stops after the first regional ignition, or after H steps if none occurs. Its median in this batch was 17.70 ms. Recorded native times include stepping and exclude capture of labels. Scanning the shell for a positive event, preparing the original simulation and restoring the live cut are unmeasured editor costs. All methods start at that same cut.

Python asset read, geometry transformation and membership preparation for both shells took 9.30 ms once. Each checkpoint read, hash and decode took 19.26–32.30 ms. Per-query preparation from a decoded cut took 4.52–6.51 ms, including construction of the relevant graph and gas groups. Each method was timed independently from the prepared state through conversion of its result to IDs. A single-frame query skips graph heating after its terminal scan. Combined evidence encoding and writing for all windows took 8.49 ms. From a decoded cut the weighted preparation, prediction and native fallback sum to a median 32.76 ms. Adding checkpoint read and decode gives a paired median ratio of 3.05×. These are sums of separately measured Python and browser costs, with one observation per query. They establish how this implementation behaved on this recording. [Timing breakdown](COSTS.json)

The current negative certificate cannot discharge the regional decision on these windows. Both positive and negative answers remain important in a future comparison. An exact positive must identify an actual ignition in time, and a complete negative must cover every eligible site. Further shell-width or placement searches on this recording would change the frozen question.

## Reproduce

The regional predictor uses the pinned T42 recipe, its external foreground PLY, NumPy, and the six full cut files generated by the T86 capture. The scorer uses only Python's standard library and committed files. The original third-party PLY and full dynamic cut files are stored outside version control.

~~~sh
python -B tracks/tog/tasks/t87-stroke-halo/regional.py --asset /path/to/foreground.ply
python -B tracks/tog/tasks/t87-stroke-halo/score.py
~~~
