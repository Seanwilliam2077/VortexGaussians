## Ordinary entry and independent reference

The ordinary adapter constructs unit rays from the documented eye/target/cross basis and finite clip distances. A deterministic median sphere BVH contains Gaussian centers (leaf size8). Each node has total k, largest h and enclosing radius. For a unit line, D=max(0,distance(line,node_center)-radius) lower-bounds every center's perpendicular distance, so U_node=sum(k)*exp(-D^2/(2*hmax^2)) bounds omitted full-line, hence finite-ray, optical mass. Traverse in fixed child order and prune only disjoint nodes whose cumulative U stays in budget. The adapter computes retained q_i from cross-product perpendicular distance. Gaussian tails and out-of-view centers are not silently discarded.

For nonnegative colors and black background, let C_k be the maximum ORIGINAL field color in channel k. Deleting optical mass at most U changes RGB_k by at most C_k*(1-exp(-U)) and alpha by at most1-exp(-U). Coupling the retained/omitted optical-event processes proves this: outputs coincide if there is no omitted event, and otherwise both first-event colors lie in[0,C_k]. This includes missing extinction masking downstream retained emission. The ordinary pruning mass budget is the minimum channel/alpha mass budget corresponding to .00025 absolute error. No omitted-only color bound is used.

Ordinary integration uses existing Gaussian-aware breakpoints and GL4/8/16/32/64 with nominal agreement threshold .000125. Empty/computed-zero and a conservative global color-box shortcut are allowed. GL rules are shared within this one qualification invocation and all their construction is counted. This wrapper explicitly forbids the old Simpson fallback: its initial unresolved-interval omission charge assumed normalized colors. Original T22 files remain unchanged. GL agreement itself is only empirical; failure to agree is a recorded failure, not permission to change the fallback or rerun.

The independent reference reconstructs rays with a direct trigonometric basis and projects ALL original centers using the residual delta-dot(delta,v)*v, rather than the ordinary cross product. It does not use the BVH omission set. Individual full-line q<=1e-10/(max(1,max(C))*N) may be omitted only with an explicit summed mass charge and channelwise coupling error added to the reference interval. An underflowed q contributes at least1e-300 to this charge; it is not declared physical vacuum. All full q/z and finite masses are retained for audit.

For remaining components, analytic Gaussian interval masses give each cell's absorption W=T(left)*(1-exp(-cell_mass)). Gaussian density minima/maxima over the cell bound the local mixture j/sigma; scaled log densities avoid interpreting numerical all-underflow as vacuum. Multiplying its color interval by W bounds cell radiance in REAL ARITHMETIC. Sum cell bounds, add reference omission uncertainty, and bisect the largest RGB uncertainty until every midpoint half-width<=.0001. Start with Gaussian-aware breakpoints at means plus0/±3/±6 widths and ray endpoints. A true empty retained list or exactly equal colors has the corresponding analytic branch with omission accounting. No GL/Simpson output enters the reference. At most8192 created cells per ray and200000 across the invocation; cap, resolution or deadline exhaustion is failure/inconclusive, never empirical GL truth. Save every final cell as a compact ledger.

Before freezing or evaluating ANY ray, reference half-width was set to .0001 (one tenth of the delivery tolerance), replacing the preparatory .00001 draft. Qualification still uses the full worst distance from ordinary output to BOTH reference endpoints at .001, so this does not relax the output-accuracy gate; a wider reference can make that gate harder. It avoids requiring an unrelated100-times-finer reference before asking the actual accuracy question. No data/result informed this pre-execution choice.

## Numerical scope and pre-fixed gates

All code uses standard-library binary64 math. BVH radii/sums/distance bounds receive conservative padding and charges use upward nextafter where implemented, but erf/exp, geometry and all interval operations are NOT a formal directed-rounding implementation. The claimed outcome is checked binary64 reference agreement under disclosed real-arithmetic envelopes, NOT a floating-point certificate valid for every input. Numerical allowance is1e-10 for output/mass checks,1e-12 for ray/clip absolute-or-relative comparisons, and1e-12+1e-9*abs(q) for independently projected q. These allowances do not excuse budget exhaustion or model changes.

Each selected ray must satisfy:

- finite unit directions and valid a<b; ordinary/direct-basis geometry and retained q/z agree under the fixed numerical checks;
- complete disjoint BVH partition, every omitted actual finite mass from the independent all-particle projection <= charged bound plus1e-10, and charged RGB/alpha error<=.00025 plus1e-10;
- reference midpoint half-width<=.0001 plus1e-10; all final leaves cover the retained integration interval with their declared ordering and sums (analytic branches declare no leaf coverage);
- ordinary RGB output's worst distance to either reference endpoint <=.001+1e-10 in every channel; alpha agrees with independent analytic full-field alpha to.001+1e-10;
- output is finite, alpha in[0,1] and RGB in[0,C_k*alpha] within1e-10. These necessary range checks supplement, not replace, the independent radiance interval.

Coverage additionally requires at least one ray with full alpha>=.001 in each of the six frame/view groups, and at least one ray over the whole subset with two or more finite component masses>=.0001 and nonconstant RGB range>.01 among those components.
