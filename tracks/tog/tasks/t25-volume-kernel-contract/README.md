## Decision and research consequence

**KERNEL_APPROXIMATIONS_MAPPED_PRODUCTION_ADAPTER_AND_CARRIER_UNRESOLVED.** This is source-level progress in deciding what must actually be compared. It avoids attributing errors from culling, mass regularization, clamp or early exit to overlap ordering, and avoids comparing differently decoded saved states.

The promising question remains whether controlling the defined continuous-overlap error has useful full-cost value on a qualified workload. T22 only established one development-selected incremental prefix win and small overlapping-range batch differences. T25 adds no workload frequency, new mechanism, GPU speed, visual benefit, novelty clearance or TOG contribution. No statement that ordinary methods lack a bottleneck follows from these gaps.

Before a later measurement contract, establish the omitted source semantics, actual trained parameters with mode/SH/camera/domain provenance, and an ordinary continuous reference meeting the chosen tolerance on that same input. A missing ready checkpoint is a route-specific evidence gap, not proof that researcher-defined or separately trained workloads are forbidden. No checkpoint download, training, fallback scene or additional source batch is automatically authorized by this completed audit; the broader research goal may justify a separately frozen finite next task.
