# Ordinary full-material replay with cached adjacency

Caching static material neighbours changes the ordinary baseline on longer windows. Using the retained cache on Firewoods gives paired median ratios of 0.813 at four frames and 0.806 at eight relative to rank-only replay. The corresponding trunk ratios are 0.661 and 0.683. All four methods share the same terminal rank-only gas operator. The high fraction of one-step and first-scan exits makes the all-window median close to one on both assets. Each asset used two browser pages, one per stroke order. Typed-array payload totals cover 2,800 cached donor rows per asset. JavaScript object overhead and allocator fragmentation add memory. These are build-cost totals over all calls including warmups. Once a row exists it can be reused at subsequent cuts on that page. A fresh-per-query cache pays the full cost on each new query; the retained cache assumes users can amortize static neighbours. The shell answer includes dispatch, branch cloning and restoring the original simulation. Separate timing runs are unsuitable for subtracting unrelated median latencies. The ordinary material step drops per-neighbour diagnostic counters and preserves the native physical/material operations. The donor cache records ordered native neighbours and exact binary64 coefficient values. Each donor still checks every cached neighbour's current state and updates each cold recipient's binary32 heat in the original order. For three cuts and both stroke orders on each asset, an untimed eight-frame comparison checked **every** material-state, fuel, heat, glow and char entry, the ordered frontier, cursor, RNG draw count and native particle-state hash against the original. A separate pass validated every callable regional question and every subsequent unmodified reference frame. Two 360-step captures per asset with four balanced timed positions and one warmup per method completed in 33.12 and 69.85 s, including setup and audits. An initial launch selected a different Node executable and exited at preflight before any scientific step. The reported captures used the pinned version.
