# Ordinary optimized regional replay and cache costs

Freeze 25 November 2026. T90 development results and the T92 event labels are known. T94/T95 performance remains unknown. Test whether output-directed solvers offer a benefit over ordinary replay that already removes per-neighbour research telemetry, uses an exact rank-only terminal scan and caches static material graph neighbourhoods. Keep the original shell, seeds, controls, 18 queries per asset, active-set and RNG order. No new settings, cuts, or scenes are selected based on timing.

Use three controls in the same callable harness: the historical rank-only method, direct whole-scene material stepping without telemetry followed by identical rank-only terminal evaluation, and that same ordinary stepping with cached per-donor neighbours and binary64 per-edge heat increments. Keep each recipient's native binary32 addition order. Use both a fresh cache for each query and an asset cache retained across queries, with first build times, bytes/entries, query dispatch, clone and restore recorded. Intermediate steps may stop at the first in-shell ignition. The implementation still advances all material that could influence the next frame and processes all the native emitter RNG offers. No future emissions or events are used. We retain the computations for visual clocks inside nonterminal steps. Exclude rendering as for the original query.

Compare per-window host-delivered medians and per-step scopes, including fast and slow cases; use one warmup and balanced repetitions. Verify positive first-frame/witness and no-event outputs against all native records, and validate complete intermediate state (thermodynamic/material/RNG observables, excluding telemetry) using an untimed check on both takes per asset. The first query's cold cost and any amortization horizon matter. Further paired comparison with T94 or T95 should use the strongest applicable result, identical setup contract and schedules; no claim of general acceleration or external user demand follows automatically.
