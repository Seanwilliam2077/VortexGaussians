# Native-buffer comparison of pending cloth feedback

Registered before requesting the device. The two buffers contain signed 32-bit words in the 13-channel Blackbody layout. Assume the caller has separately established the layout, enabled hooks, gas state, forcing and clocks required by the [frozen T130 test](../t130-independent-fx-choice/FEEDBACK_TEST.md). The operation returns **raw**, **axis** or **split**. Implement raw equality and the frozen per-axis sufficient predicate on resident buffers, with one scalar readback for a host decision. Also measure a dedicated raw-only device comparator. A new kernel may help even if the final editing operation has no useful sharing window.

Use the pinned Blackbody and NVIDIA/D3D12 setup from T131. Run a single fresh device worker with a 180 s total limit. Record device setup, program construction, resident buffer allocation/upload, first call by method, and per-call wall clocks. Include the command recording, result reset, queue submission, synchronized readback, and decoding in timed device methods. No agent or native simulation runs on that device concurrently. The input arrays are uploaded once per pair before the timed comparison. New online acquisition, hook guards outside this buffer comparison, physical updates, branching, and drawing are separate costs.

Compare both classifications against the frozen NumPy rule and raw equality on the two real T131 grids and on deterministic constructed controls. Include a one-cell input, 65 and 129 cells, equality even for negative words, individual scalar and steam mismatches on a trailing cell, negative area, mixed qualifying axes, support mismatch far from the live impulse, and disjoint workgroups where every local region qualifies but an axis globally fails. Test each axis and deliberately alternate passing and failing inputs using the same result allocation. Zero or mismatched buffer size is an invalid call. No threshold fitting or shader change after opening device comparisons.

Time the archived frame-1 versus itself, frame-1 versus frame-2, and frame-1 versus itself with one final steam word changed. Compare 1,024 cells at original size and 65,536 cells by exact data repetition (bandwidth control). Methods are device raw, device raw-plus-axis, optimized CPU raw and CPU raw-plus-axis from a batched full GPU readback, and CPU raw-plus-axis from two separate ordinary Blackbody reads. The batched control copies both native buffers in one command submission, then reads the joined buffer once. Capture one untimed-for-summary first call per method per pair, then 15 timed blocks of all five methods in cyclically shifted order. Report median and every sample, bytes read, and identical output decisions for each equal-contract comparison. An observed isolated speed advantage requires a lower device full-guard median than both full CPU comparators for the named input/size. The raw-only operation cannot certify an unequal pair. Every result is confined to this device/implementation.
