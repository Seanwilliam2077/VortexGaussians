# Held-out second geometry and two-point ignition edit

This protocol transfers the original exterior-brush question from Firewoods to a long fallen trunk. A graphics researcher stages a burn first on one end of a log, then on the other, and asks whether fire will spread outside the second brush. There is no participant or artist observation. The external geometry is [Dead Tree Trunk by Rob Tuytel](https://polyhaven.com/a/dead_tree_trunk), distributed under [Poly Haven's CC0 asset license](https://polyhaven.com/license). The source is a mesh of a weathered log. We make material splats from its vertex positions. The production method of the original mesh has not been verified. This is a change of geometry, point density and initialization seed; this asset does not test trained Gaussian reconstruction or appearance quality.

Take the object's one untransformed glTF mesh at its authored world scale, with no textures. Retain unique float32 vertex positions in their original order (welding UV/normal seam duplicates). Use native mean-centering and vertical lift. At one quarter and three quarters of the trunk's x extent choose the vertex nearest (x fraction, maximum y, midpoint of z extent). This chooses reachable points on the upper bark at opposite ends before any simulation. The native spherical brush radius is 0.12. Use the same radius for each location and both orders. Semantics, site positions, controls, seed 23 and file hashes are fixed in recipe.json before inspecting any dynamic outcomes.

Use the same native solver, step and global/per-layer admission schedule as T86, using world-fixed gas layers and the existing diagnostic camera. Reset before each take, ignite at frame 0 and after frame 180, step to frame 360, and export native event records and checkpoints at 210, 240 and 300. For each cut test H=1,4,8; an eligible target is cold, has positive fuel, and lies in the shell 0.12 < distance ≤ 0.26 from the second brush. Record per-query eligible size, all native in-shell first ignition events, earliest frame and a stable lowest-ID witness on that frame. Native true/false, empty regions and all-negative/all-positive takes are all valid outcomes and will be retained. Include the actual zero-time edit IDs. No new location, seed, scene, window or conditional retuning. No requirement that positives occur. Compare both AB and BA even if one initially ignites few sites.

Two 360-step reference trajectories, zero intermediate renders, no use of T91 predictions. The capture derives scene-independent instrumentation from the unchanged T86 native adapter and checks all discrete active counts against the trace, the geometric brush contacts, retained cut material states and final fuel state. Strictly separate a regional scene transfer measured on this asset from generality across different solvers, materials or independently authored workflows. If T90/T91 are measured on these frozen windows, include direct native and actual query result costs. Release results after the candidate logic is frozen to preserve prospective transfer assessment wherever possible.
