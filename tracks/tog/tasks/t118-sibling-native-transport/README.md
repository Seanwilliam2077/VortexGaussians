# Constructing the full brush's simulated state from its lighter sibling

Once the light stroke has run 24 steps on Firewoods or 16 on Playground, its state can be turned into the exact full-stroke state on these two fixed inputs. The procedure uses the common parent and the known zero-time brush footprints. It takes the ordered gas and RNG from the light branch, patches only the extra painted material (214 or 1,317 sites) and reconstructs the full branch's native frontier. It consumes no full-stroke future. [Qualification and proof](../t117-sibling-prefix-transport/README.md) · [Registered test](PROTOCOL.md) · [Actual implementation](transport.js)

Separate native full-brush continuations matched every byte of the five material arrays, each ordered frontier entry, every particle property, cursor, RNG and the other physical state fields. The direct comparisons covered the transport boundary, the following step, the woodpile decision's +44 step and the +90 deadline for both scenes, eight states in total. The material arrays covered 589,679 bytes on Firewoods and 1,360,391 on Playground at each check. The reconstructed branch also reproduced the ordered newly ignited IDs in the independently archived native trace for every one of the 90 future frames on each asset. The starting editor state was restored after both forks. Diagnostic historical counters are excluded. [Receipts and runtime identities](evidence/CAPTURE.json)

These are the original two known editing decisions. A full-stroke computation was necessary on the woodpile. The Playground action accepted the light brush immediately, so any checkpoint taken for the second stroke is pure overhead on that action. Timed complete decisions must charge that speculation and compare against the same early-stop ordinary solver.

Run `python verify.py` with the repository's portable native ledgers. The independent state equality loops themselves run inside the original browser solver. To repeat them, stage the registered foreground PLY files through [T109](../t109-common-parent-choice/README.md) and [T101](../t101-playground-holdout/README.md). From this directory run `node run.mjs FRESH_OUTPUT_DIRECTORY`; the output directory must not already exist. The browser and Playwright paths can be supplied with `BROWSER_EXECUTABLE` and `PLAYWRIGHT_MODULE`. [Native harness](run.mjs)
