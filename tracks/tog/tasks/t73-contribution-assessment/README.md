# T73 — 现有机制的有限贡献筛选

本轮不保留技术候选。评估角色是只读分析：先确认文件名，读取指定记录及三份直接支持的数学文档；没有新增检索、科学运行、原始数组读取或代码修改。本文件只记录结论，不建立新协议。技术核心仍未成立；**2/6 是原独立评审的保留评分，不是本次重新打分。**

热势收缩有实现价值：以五维径向热核表示逆 Laplace，再消去高斯乘积的空间积分，每个候选的弱 Euler 作用量化为逐分量对的一维积分。但其机制仍是普通热势表示与高斯积分的组合，未消去几何搜索或目标范数的额外成本。对 K 个当前分量、M 个候选，仍需约 K²M 个收缩。最强普通替代应允许共用求积节点、缓存当前态 F(q)、批量候选内积及相同解析核技巧；不能只比较每个候选重新求解网格的弱实现。现有记录没有建立相对这些替代的质量—总成本差异，公式正确或积分维度降低不足以承担贡献。

出生方向也未显示独立能力。投影掉旧切空间后，β*=max(0,⟨R,eθ⟩)/‖eθ‖² 是普通单侧最小二乘；冲量补偿给出可行方向，却没有建立新求解能力。最强普通替代是允许零权分量、完整权重边界和几何优化的有限步场投影。T70 已从精确初态选出两个正且不同的分量，故重合 Jacobian 降秩不能单独构成专用出生器的需求。δ∼√h 的分裂尺度表明参数坐标可能奇异，并不证明普通场投影受阻；T69 所列对称保矩分裂的首个新项与初始奇残差正交，也未给出改善机制。

据此关闭两项窄开发路线：**把现有热核收缩包装为新方法，以及仅为解决精确重合启动而开发专用出生器。** 这不排除热势评估或混合物动力学中的其他研究机会，也不由当前基线的时间敏感性推出全族失败。T72 的半步邻域反事实仍属普通维护提案，不能通过此筛选自动变成贡献任务。

可推翻这一筛选的证据应包含新增机制及能力分离。例如，在分量数、尺度比和近重合变化下，相对充分优化的普通评估器建立统一误差—成本收益，且计入范数、失败候选和确认成本；或展示普通场投影以同等信息与预算未能取得、由出生机制解释的能力差异。当前文档没有这样的分离证据。新的数学或比较证据可以重开判断，但本文件不安排其执行，也不以未完成文献定位断言全领域没有原创空间。
