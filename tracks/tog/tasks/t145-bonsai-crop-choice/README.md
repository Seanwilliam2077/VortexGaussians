The full-frame reference reproduced the native RGB hashes of all four branch/control frames, both original physical endpoints and their one-step native successors. The positive target contains 2,996 two-by-two blocks in a 156 × 164 pixel rectangle. Both branches returned a changed mass of 0 out of 411.0941503196955. This run also records the four distinct reference crop digests. The first restricted draw stopped at its guard after 13.95 seconds, before either optimized method produced an image or timing. The registered stop ended the sequence.

The guard required a paused UI at the endpoint. The original [trial reset](../t98-edit-to-answer/click.js) calls the [branch fork](../t90-callable-regional-query/query.js), which explicitly clears the pause flag. On the registered embedded view the animation callback immediately returns and manual physics stepping owns the clock. T145’s guard therefore rejected the correct live branch. The bounded [T147 recovery](../t147-bonsai-crop-recovery/README.md) retains this receipt and independently verifies a correction.

[T144's full-frame diagnostics](../t144-bonsai-repeated-cost/README.md) found 45 and 183 altered display pixels within the target in the two branches, with maximum channel changes of one and two levels. A claim that their gas has no pixel support in the target already contradicts these observations. Pre-edit exclusion would require a conservative upper bound on future projected intensity and compositing through the sorted scene. Its validity and cost remain open.
