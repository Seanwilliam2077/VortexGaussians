## 问题与交付

能否提出一个值得下一步资格化的、与可编辑三维场景或物理效果相关的具体操作，其新增能力或完整成本收益不是现有普通工作流已提供的？先明确操作和可能机制，再决定是否值得实现。最多提出三个**操作不同**的候选；禁止把同一缓存、零空间搜索、普通形变/投影换名称充数。

每个候选在检索前写出：

1. 输入、要完成的操作、交付结果，以及为何这个操作有研究价值。研究人员定义任务允许，但不能编造创作者需求或声称已验证价值。
2. 一个具体、可检验的机制主张，或系统中有因果关系的瓶颈；列出可能使该主张失效的假设。界面、组件组合和额外参数本身不是主张。
3. 最强普通工作流/方法如何做同一件事；双方获得相同信息、自由度、热启动和必要工具，计入建立、维护、失败及完整验收成本。
4. 可取得的最小输入，或明示为研究人员合成的资格例；它只能检查机制，不能代替实际任务收益。不要先下载/制作大资产。
5. 一个最低成本的否证条件：何种已有方法、解析结果、普通基线或输入限制会让该候选直接停止。不要依靠事后收紧保护门制造困难。

## 固定预算与选择

最多两轮定向检索、最多六项直接相关的原论文/作者实现来源，按三个候选分配；允许现有本地证据直接淘汰，不为凑数补搜。无训练、模拟、求解器开发、大资产下载、安装或外联。不自动创建多份实验实现。

交付一张候选比较表、具体先例覆盖、未解决问题和一个明确选择。只有输入/评价有可行入口，且机制有超出现成普通能力的可否证预期，才保留**最多一个**并写下一项有限资格协议。选中不是证明新颖性、优势或可录用。

如果三个候选均不值得进入准备，就记录目前没有可支持的核心假设，并列出改变该判断所必需的具体数据、技术条件或作者决策；不要自动重复另一批换名候选，也不要重新启动已关闭实验来消耗额度。持续研究不以填满运行队列为完成标准。

T15 不要求回到原方法承诺，也不因一次来源核查失败否定所有物理编辑研究。任何以后重新进入 D03 的任务都要有新增证据，不能只用本次重新命名作为重开依据。
