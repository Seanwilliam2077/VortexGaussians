# A21 作者决定的独立审查

2026-10-30。本次仅阅读 A21 [SOURCES](../art/studies/a21-paper-offering-position/SOURCES.md) 与 [DECISION](../art/studies/a21-paper-offering-position/DECISION.md)，未新增搜索、看图、运行或设计作品。本意见不是新评分；A20 历史 **3/6** 及其余评分保持不变。

**决定已有足够依据支持一次有限的实际修订，但尚不能把撤火视为新的艺术贡献。** 它不只是为隐藏黑底窗而删去效果，也撤回了原本由这段火承担、实际却未充分成立的“送出”承诺。保留纸房为尚未由本作完成送出的赠礼，并明确关门不代替收讫，形成了可以实际检验的立场变化。当前仍只有决定，没有修订后的形式证据。

所要求的信息缺口得到实质但有限的补充：资料记录中的可读正文把特定台湾展览及香港材料里的纸制物件、亡者日常生活和焚送联系起来，也使“日常照料、房屋与拖鞋不是本作独创关系”有了比 A20 更具体的依据。这不是完整文化谱系，更不是资料要求本作必须焚烧。资料 Agent 的三项读取与 root 两项复读超时已分开披露；我没有重开原文，不能增加独立核验程度，也不能用 root 的超时抹除先前读取。

作者的取舍在这条边界内成立：没有事后把首试的黑底拼接包装成原定媒介批评，没有将未焚烧宣称为更尊重，也没有让门替死者行使真实意志。“尚未送出”应继续是本作自定的呈示位置，不是对信仰效力或所有纸供品如何交付的判决。撤火也不会使纸房与亡者的文化关联消失。

下一次实际修订值得检验的，是撤去点火动作后，保留的住处、内外观看位置与关闭的门能否共同让赠予者的有限能力变得具体。若实际变化只是画面更干净、流程更短，而“未送出的礼物仍被赠予者收起”完全由新说明添加，就只能记为删除了一个没有承担作用的部分，不能把自我纠正直接升格为贡献。这一判断不要求新增真人故事或把门做成动画。

**范围代价不能淡化。** 撤去外火意味着这件作品将移除与 VortexGaussians 原火焰平台的直接材料联系，剩余表达主要由绘制的房间与网页观看流程承担。因此，这支修订可以推进由原项目引出的艺术命题，却不能单凭它兑现保留原火焰平台艺术价值的目标，也不能被当作原仿真方法的艺术验证。是否接受这一范围转移，应由 root 在决定制作时明确承担，不能只称为完善原方向。反过来，Art Papers 并不普遍要求特定渲染器或新算法；联系减弱是本项目目标的代价，不是此作品自动失去艺术论文资格的理由。

我支持上述一次有界形式修订的判断，不替作者设计替代作品，也不启动制作。旧首试、来源访问差异及历史分数均应保留，实际修订完成后再判断其艺术信息增益。
