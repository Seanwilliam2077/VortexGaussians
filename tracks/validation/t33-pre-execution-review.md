## Mathematical and implementation findings

For a true interval `L <= C <= U` and a fixed output `g`, the maximum of `abs(g-C)` is attained at an endpoint. Requiring both endpoint distances to be at most the unchanged `.001 + 1e-10` is sufficient. A strictly disjoint interval disproves that output under the same enclosure premise; overlap without containment is unresolved. Empty and equal-color paths use the same test. The implementation never accepts midpoint agreement or intersection alone.

The worker computes ordinary RGB before independent projection/reference work and passes an immutable tuple. The answer is read only for domain checks, stopping assessment and diagnostic reporting. It does not enter optical projection, omission thresholds, density/color bounds, cell weights, initial breakpoints, heap priorities or bisection choices. The remaining reference diff consists of the answer/tolerance interface, endpoint stopping/control flow and reporting. Per-cell bounds and partition refinement are not tightened. Stopping may occur sooner because the output is already decided; it does not alter the field or select different rays.
