## Formulas, comparison and cost

The two implementations match the fixed definitions: each independently computes finite retained Gaussian masses and `alpha=-expm1(-tau)`; sorted output uses mean/source-ID order and prefix attenuation, while mixture uses optical-mass-weighted color. Black computed-zero paths and zero-mass omissions are explicit. The compensated prefix expansion does not change the real-arithmetic formula; its actual steps/sum lengths are counted and no strict-linear implementation claim is made.

Each arm owns its BVH, camera, ray preparation, partition, projection, finite-mass and output work. Shared source/import/decode costs are separately included in total computation. The worker loads T22's module to call its normal-interval routine; it never calls GL integration or a reference implementation. No method receives previous RGB, endpoints, pixel identity or an accuracy result. The full fixed sorted pass precedes the full fixed mixture pass, so timings are not a randomized comparative benchmark.

Only delivered values are classified. For a valid saved interval, all three far-endpoint distances within epsilon give RGB class 1; any shortest distance strictly above epsilon gives class 2; otherwise class 3 is unresolved. Alpha failure overrides RGB for the joint label. Inaccuracy does not abort execution, whereas invalid values/contracts do. The fixed foreground is inherited from T35 full alpha and has denominator 986 regardless of completion; evaluated foreground is separate. T36 RGB contributes only unamplified display differences and does not supply truth or an output selector.

Old blue is excluded by positional legacy decoding. Reference bounds remain applicable to the unchanged field even though the old answer determined their stopping time. Old per-source projection/omission checks are inherited under frozen inputs/code plus deterministic noncolor reproduction, not claimed as freshly independent source-level validation. An unresolved arm must not be called a definite failure; cheap-rule failures do not establish failure of optimized integration or a need for a new method.

## Persistence and stopping

The `<12d6I` record has 18 distinct names and separates RGB, tau, near/far, classification and status. Actual bytes and all positional values are checked before and after status commit. Finalization decodes saved records, rechecks contracts and classification, and distinguishes valid records from accurate records. Class maps show qualified/failure/unresolved/unfinished explicitly. The literal test independently checks layout/types, distinct HDR blue/far, valid black and unfinished slots, inclusive/strict classification thresholds, an unresolved interval, actual saved corruption and forged classification. It also checks complete but inaccurate records and a clearly labeled nonphysical literal used solely to exercise the alpha veto. PNG values are independently decoded. The test does not evaluate either method on synthetic or real rays.

One exclusive invocation, 60 s computation, 90 s outer wait plus 10 s cleanup, and 16 MiB new numeric evidence are fixed. The planned binary extent is 11,796,480 bytes. Exceptions/deadlines preserve partial evidence without retries, budget escalation, post-timeout evaluation or reference refinement. Prior T35/T36 costs and failure scopes remain explicit.
