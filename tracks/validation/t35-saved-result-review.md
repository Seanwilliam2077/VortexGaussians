# T35 independent saved-result review

**Saved-evidence audit failed. T35 does not deliver an independently auditable complete RGB image.** The worker and supervisor retain their original success receipts; those receipts describe the in-memory checks and completed invocation, not a valid saved RGB result. No frozen file or historical outcome was changed.

## Blocking defect

`t35-first-complete-frame/evidence.py:11–14` declares `b` twice in `FLOAT_FIELDS`: the blue channel (float slot 2) and far clipping distance (float slot 25). `run.py:259` initially copies the correct three-channel ordinary answer, but `run.py:265` overwrites `values['b']` with `ref_ray['b']`. `evidence.py:38` subsequently writes that same clipping value into both slots. The set-based schema check at line 36 cannot detect the duplicate name. The original ordinary blue component is absent from the saved pixel records.

The single independent auditor invocation checked 1,227,213 conditions and reported **98,304 failures: RGB range and endpoint qualification fail for each of 49,152 pixels**. Saved blue values range from 50.00027781974393 to 62.53017242615844; the source blue maximum is only 1.8826904508437203 and alpha is at most 1. The saved maximum RGB endpoint discrepancy is 62.53017242615844. A subsequent focused saved-byte arithmetic check, not a rerun of the auditor or any scientific method, confirmed the blue and far-clip slots are bitwise identical in all 49,152 records. This is a serialization defect, not evidence that the ordinary numerical solver produced those blue values. Its pre-serialization checks used `answer['rgb']` directly (`run.py:249–254`).

The packaging code also reads the overwritten `b`, so `rgb.png`, saved RGB minima/maxima and the saved RGB error summary are invalid as ordinary-renderer output. `all_pixel_records_qualified` and the white mask mean all status flags were committed; they do not independently qualify these corrupted colors. The worker checks counts and final status, but does not reject this contradictory saved error summary.

This reviewer and the other pre-execution reviewers missed the non-unique field name. The frozen pre-execution review is preserved. The independent post-run endpoint/range checks caught the mistake; its original failing report and auditor source are preserved without rerun.

## Scope and next boundary

No scientific module was imported or rerun for this audit: only saved bytes, hashes, PNG structure/masks and stored arithmetic were inspected. The audit cannot reconstruct the lost ordinary blue channel, and a reference midpoint would be a different output rather than recovery of that channel. The corrupted RGB PNG must not be presented as a successful full-frame rendering. Alpha, retention and reference ledger evidence may be discussed with the limitations above.

The next finite implementation check is a collision-free schema (for example `rgb_b` and `clip_far`), an explicit unique-field assertion and an exact record round-trip using distinguishable literal field values. It should compare all unpacked fields, then require the actual saved RGB/alpha output gates after packing. This test needs no renderer or new scientific input and would have detected this defect.

A **separately frozen ordinary-only full-frame replay against the existing reference endpoints is sufficient in principle to qualify a new RGB delivery**, without recomputing the reference. The inherited interval construction and subdivision priority do not use the ordinary answer; that answer affects when refinement stops. A stored interval that encloses the fixed field therefore remains applicable to another output, even though it was selected by an earlier output's stopping test. Existing endpoints, full alpha and complete reference ledger identities must stay fixed.

For such a new one-invocation task, predeclare identical carrier/frame/camera, ordinary/adapter/kernel source hashes, original row-major order and an initially empty unit-rule cache. Compare all three newly saved channels to both existing endpoints at `.001+1e-10`, and new alpha to existing full alpha. Require new R/G/ordinary alpha and ordinary path/order/retained-count/mass-charge fields to reproduce their unaffected historical values exactly. Old stored clipping endpoints come from the independent ray implementation, so compare newly formed ordinary clip endpoints with the original normalized tolerance rather than assuming bitwise equality between the two implementations. The full per-pixel primitive partition and omitted-mass source arrays remain unstored: source identity plus deterministic execution is the basis for reuse of their old verification, not a new independent reconstruction of those arrays. Fail rather than relax these gates if reproduction disagrees.

This would qualify a newly generated output, not recover the original blue component or retroactively validate T35. It requires its own bounded protocol and freeze; no such replay or sentinel test occurred in this audit. T32/T33 remain failed, T34 remains qualified only on its fixed subset, and no TOG contribution is established.
