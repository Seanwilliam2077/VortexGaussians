# A10：第二次点火——一次负面排练

这次排练完成了固定动作，却没有把“再点一次”发展成足够明确的艺术关系。30 秒和 31 秒仍有醒目的火焰；第二次点火没有新增点，主要靠界面文字才能辨认。不给这段记录补写“拒绝奇观”的意义，也不据此继续剪片或主张贡献。

它使用原艺术页面、原合成示例和默认位置／视角，由 Agent 操作。没有个人记忆、真实毁损或观众反馈。动作是：点火 → 10 秒 → 10 秒 → 10 秒 → 同处再次点火 → 1 秒；31 秒结束，不重置、不换角度、不补料。30 秒只是预定制作长度，不是耗尽或自然熄灭判据。

## 实际限制

独立 UI 读数、截图和压缩影片取帧不是原子记录。名为 `decoded-05-twenty-seconds.png` 的实际解码图显示 20.02 秒，已进入下一段且页面滚到控制区，场景大部分在视口外；不能拿它说明 20 秒的完整形体。其余晚态样本中，红色羽流、明亮根部和底层形体仍可见。30 秒的再次点火前后，最明显变化是状态文字，而非画面中的新事件。

只目视了九张固定解码图，没有宣称完整连续观看。全解码通过、来源未变、工作流完成均不等于艺术有效。一次运行约 92.45 秒；没有第二次录制、修剪、模拟修复或新增论文。当前结论是保留有用的负面排练，后续作品选择尚未执行。
