# A13：视角进入材料状态

2026-10-30。一次预先限定的五臂实验完成，状态为 `completed_qualified`。在同一合成场景、点火和六秒推进下，视角改变了热量与点燃分类；**没有测得不同燃料损失、炭化或余辉**。这为下一件作品提供材料依据，不是艺术贡献、新物理模型或投稿评分。

## 实际结果

[协议](PROTOCOL.md)固定同一45808点、seed20261027、同一世界位置点火、每臂360步和13次概要。五臂初态及2483点点火集合相同。终态截图统一为yaw0；相机统一和两次render均未改变导出材料状态。view的yaw.5表示90°。

| 导出终态比较 | heat不同点数 | 点燃分类不同点数 | 最大热量差 | fuel / char / glow不同点数 |
|---|---:|---:|---:|---:|
| view：0° / 90° | 4339 | 65 | 0.7369338274002075 | 各0 |
| world：0° / 90° | 0 | 0 | 0 | 各0 |
| view：0° / 原定重复 | 0 | 0 | 0 | 各0 |

view分类变化为50个0→1、15个1→0。world负对照与重复基准不仅逐点一致，全部13份概要也严格一致；比较概要仅去掉yaw和sliceMode。view在第30步的保存概要已不同，在第90步首次保存到不同随机调用数。采样不能定位精确首个分歧步；此前调用总数相同也不能证明随机事件一一对应。因此终态差异属于含随机反馈的完整生成过程，不能单独归因为几何映射的直接效应。

[源码与时钟配额解释](LIMITATION.md)说明本次燃料等字段零差异：初始2483燃点超过legacy每步1400上限，六秒内共同前缀未退出，新增燃点未得到时钟服务。这是本配置的限制，不据此追加仿真。

- [监督收据](supervisor.json)：唯一worker观察生命周期188.09926789999008秒，父终态检查188.10610049997922秒；没有超时或执行错误，context/browser/server关闭。包含载入、五臂、导出和清理，不包含编程、审查和写作。
- [独立保存证据复核](../../../validation/a13-camera-coupling-review.md)解压全部15份、核对SHA256并直接重算比较；成功读回脚本2.2446633秒，命令3.1650012秒，无重仿真。审查者参加过preflight，非盲审。
- 物理worker前的控制与代码检查见[CONTROL_REVIEW](CONTROL_REVIEW.md)。独立读回首次命中Windows Store的python占位符，随后改绝对路径成功；主执行者首次元数据摘要命令有字典括号语法错误，修正后只读既有结果。这些准备／读回故障没有触发第二次物理运行。
- 艺术worker与TOG历史指定科学子进程小计2017.6732525997795秒分别报告；任何一个都不是整个项目的成本。

原demo、资产和API未改动。[run.mjs](run.mjs)与[execute.py](execute.py)保留首次流程、预算及不自动重试规则；已完成目录不能作为追加运行输出。实验只检验公开导出的状态，不保证覆盖所有隐藏内部状态。
