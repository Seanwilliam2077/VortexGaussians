# 《下次张贴之前》动作与材料规格

2026-10-31。A25实现者在观看A24实际结果后选择本谱，本文件在A25首次正常UI运行前固定。作品保留[创作者回应](../a24-signature-material/CREATOR_RESPONSE.md)的新立场，也保留“亮火遮暗变”原承诺未获支持的记录。题名不将当前页称为下一版声明。

## 一次观看

起点是一张仍列三人名字的共同声明。旁边的请求折起，观者知道另有一句话，却尚未读到。`#read-request`展开请求：叶青希望下次张贴不再署名，另两人保留正文。初态材料始终停在0步，读多久都不消耗模拟步。

`#begin`写明“收起原话，查看处理”。观者已读过请求后，才可选择这个动作。它将原话折回旁边，开始唯一火序列；名字、共同正文及处理图像继续公开呈示。折起是作者安排的观看分离，不冒充删除了请求或取得了现实处理授权。

处理中，`#request`可以把原话放回图像旁，也可以重新收起。此动作不改材料、不暂停、不重启；如果需要停留阅读，可另按`#pause`。通过让原话离开、再回到同一并列署名旁，作品邀请观者对照正在观看的突出与收到的具体要求。它不宣称观者必然遗忘原话、误认叶青为主角，或已经发生某种心理转变。

六模拟秒到达时，材料停在frame360，原话保持观者当时选择的展开或收起状态。界面明确“本版停在处理期间”，并说明没有制作下一张声明；不宣布燃尽或处理完成。如果请求仍收起，观者仍可把它放回。无限停留不是继续模拟。

`#finish`在初态之后随时可结束本次观看，停止推进并让声明、姓名和请求一起退出当前呈示，只留下结束语。没有生成新的声明，也没有删除模拟状态。结束不是完成或拒绝叶青的请求，更不说明真实署名权利发生变化。作品内没有再次开始、重置或重燃。窄屏初态退出路径同样允许，不必先读或处理。

这不是强制依次通过的任务奖励流程：可以不读、读后退出、处理中暂停或提前结束。作者承担的是先使请求可读、再允许暂时分离原话与处理图像、最后把是否重新并置留给观者的具体编排。普通HTML规则承担这项观看关系，不声称火对所有媒介不可替代。

## 不变的材料

全部名字、栅格、点材质、点火、相机和参数均逐值沿用[A24规格](../a24-signature-material/WORK_SPEC.md)。`work.mjs`的固定常量、字形构造和摘要函数直接沿用A24对应段落，不依据A25观测改效：local Microsoft YaHei、64px字体、每名字144×80栅格、步距2、alpha≥128、.008单位/px；名字中心x=-1.4/0/1.4，y=.75、z=0；scale=.0102、opacity=.94、RGB[.82,.78,.67]、fuel1。字体内部别名仍为A24Raster以保持原生成字符串。实际点数由本次相同构造记录，不预写为已验证。

相机yaw0、elev0、dist3.4、fov.85，world切片；1200×600原画布及完整等比复制，无局部抹字。点火固定(0,.75,0)、r=.40；初始点火不在1..1400即停止，不调参。layered VPM 9层×160、seed20261031、legacy时钟/点测度、block规则、基础emitter关闭、sceneFeed及flameHeat开启，其余烧损/传播/渲染默认值保持。初始化setScene一次、research.reset一次，点火只在begin一次。

唯一物理序列360步、dt=1/60，每RAF最多一步；此版连续推进，不再使用实验页的三个“推进2秒”按钮。暂停/继续仅改变墙钟间隔，不追赶漏帧、不批量step。原模型的每步输入和上限仍固定。A25运行仅检查这个观看谱，不重新挑选A24效果或建立新物理优势。

正文和请求都是静态HTML，无燃烧、修改或下一版操作。已知A24六秒时744个叶青点仍state1/glow1、燃料非零，这决定本版必须披露“处理中”；不将本次截点推演为永久发亮、燃尽仍亮或永不消失。A25自身实际状态另由正常运行记录，不能提前写成已通过。

## 只读接口与正常UI

`window.__a25`只提供`ready` Promise和`snapshot()`，没有推进、跳段、强制结尾或改参方法。snapshot记录phase、frame、simSeconds、requestVisible、requestReads/requestToggles、resetCalls/ignitionCalls、initialLit、geometry、事件及errors；`material`、`groups`、`total`和`hash`从原公开状态只读汇总。每次返回独立副本，不暴露巨量逐点数组或可写引用。

| 阶段 | 进入动作 | 材料与请求 |
| --- | --- | --- |
| ready | 初始化完成 | frame0；请求折起 |
| request | `#read-request` | frame0；原话展开；可begin或finish |
| running | `#begin`，或paused时`#pause` | 首次点火后连续推进；begin会收起原话 |
| paused | running时`#pause` | 当前步停留；`#request`仍可改变原话可见性 |
| held | 正常达到frame360 | 无继续推进；原话可收起/放回 |
| ended | `#finish` | 当前图像退出呈示，材料保持；不重开 |
| error | 载入、资格或执行错误 | 停止且披露，不自动重试 |

`#request`只在running/paused/held显示，当前折起时文案为“把原话放回旁边”，展开时为“暂时收起原话”。`#pause`在暂停时显示“继续处理画面”。正常检查可在处理中暂停、放回原话、再继续，记录实际frame；无需把截图精确命名为2或4模拟秒。页面不会为了截图另走隐藏步长。

root依BRIEF最多一次完整六秒UI路径与另页窄屏初态退出，≤120秒、≤10图、≤16MiB。第二页不能点火。没有录像、效果修订或额外序列；检查实际运行前，本实现者仅交付四文件与静态语法核查，未启动浏览器或仿真。

最强反读仍是普通姓名高亮加火，再由文字赋予撤名含义。此谱新增的是原话与图像可被观者分离、重新并置的具体动作；其艺术分量及持续时间是否足够，须由实际呈示和独立审读判断。制作完成或行为核查通过都不预支论文贡献或分数。
