# 《三次归档》 / Three Archives

84秒单屏静默影片，1280×960、25fps。**同一次合成燃烧事件，被编辑为三份保留内容不同的档案。** [观看影片](run-01/study.mp4)；[七帧目视记录](run-01/inspection.json)；[编码前作品谱](INTENT.md)。

先出现载入、燃烧与重新初始化。之后，恢复后的同一图像保持原位：档案I静置16秒，档案II增加重置前的模拟时间与燃烧／炭化点数，档案III按次序显露实际发生的动作节选。结尾三幅同源图像并排，随后图像在剪辑中退出，仅留下不同密度的文字与空框。原始文件没有删除；三种编辑版本均不保存完整模拟状态或经历。I沿用的截图本身仍有0.00s及合成声明，不能称为无数据的纯图像；缩略图中的原UI小字较难辨认。撤图后“只留图像”标签和框线也仍在。

材料只取自[A06的一次Agent操作](../a06-char-and-reset/README.md)。10.00模拟秒、3,320燃烧点、1,400炭化点及重置后0/0均有原记录；它们不是现实损毁程度。源空间为合成测试示例，不声称私人记忆或真实场所。字幕中的动作来自实际日志，显露间隔是编辑节奏。三个档案及其并排画面不曾在原界面同时出现。

[实际制作过程](PROCESS.md)记录这次选择及其代价。Agent选择了静默、长静置、相同图像和保留空框；这些是已发生的制作决定，不是代写用户体验。当前检查未连续播放全片，也没有观众反馈。作品与论文是否形成艺术贡献，交给独立评审；本页不自行给分。
