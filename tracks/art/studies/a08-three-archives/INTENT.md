# 《三次归档》：编码前写定的作品谱

2026-10-30。本轮选择单屏静默影片，84秒，1280×960，25fps。作品以一个合成测试空间的一次 Agent 操作作为材料，不借用作者的个人经历，也不制造观众反应。三个档案是对同一次事件的三种编辑选择；不是三次模拟、三个原始界面或完整状态备份。

问题限定为：当恢复后的画面相同，什么被编辑保留、什么仍然不可知？A07把图像与摘要同时说明；本片改为依次剥离和增加档案内容，最后让图像在剪辑中退场，留下不同密度的文字与空位。数字不代表真实损毁；火只来自已录制的模型事件。此处不主张这种形式已经原创或有效。

## 固定时间谱

| 片中秒 | 内容与明确选择 |
|---|---|
| 0–4 | 片名《三次归档》，短句“同一次燃烧，三种保留。”；声明合成、Agent操作。 |
| 4–8 | 已载入图像，按A07裁切，静看4秒。 |
| 8–21 | A06源片5.10–18.10秒，保持该片时间，不插帧；源是采样画面，因此不是实时模拟速度。 |
| 21–25 | 切为重置截图；不倒放。 |
| 25–41 | 档案I，仅重复同一重置图像，16秒静置；不以新增字幕填满等待。 |
| 41–55 | 档案II，同图像原位不动，保留重置前10.00模拟秒、3,320燃烧点、1,400炭化点。 |
| 55–69 | 档案III，同图像原位不动；依次显露载入、一次点火、推进10.00模拟秒、一次重置、展开回执。只呈选定动作次序，不伪造完整日志或实时动作间隔。 |
| 69–78 | 三张完全相同的重置图像并排，分别只有图像、摘要、动作节选。相同像素不等于相同档案。 |
| 78–84 | 三幅图像同时撤下，保留框位与文字；“图像退出。记录仍不完整。”之后明示这是剪辑撤画面，源文件保留。 |

全片使用微软雅黑，克制的米白/琥珀字色、近黑背景。中段图像始终850×530，居中于(215,190)；最后三图340×212，避免将不同图像尺度误当物体运动。没有音轨、音乐、新场景或浏览器操作。字幕具体字句、显露时间、素材SHA在edit-plan.json中固定。

实际制作由Agent选择时长、取景与文字排布，并记录发生的取舍；这不是代写用户情绪。一次主编码，最多120秒。若失败保留run-01，任何修复另开run-02且说明原因。随后做flat元数据读取、全片解码和7个固定时间抽帧，目视抽帧只支持版面与可读性判断，不冒称连续观看或观众效果。完成后交独立评审，本轮不自打分。
