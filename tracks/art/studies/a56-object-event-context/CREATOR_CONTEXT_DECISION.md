# A56 原创作者决定：来源提出挑战，值得限定性修正论证

2026-10-31。我全文读完本轮 `BRIEF.md`、`ACCESS_ADDENDUM.md`、`SOURCE_READING.md`（含最后追加节），并重读A53 `PAPER.md`和A55自己的定位决定。我选择：这次材料暴露了现稿一处值得实际修正的论证限制，不能只给旧主张配上引文。修正应收窄排他措辞及其推论，不宣称新增艺术贡献，也不改变固定作品。本文只提出这个作者决定，未实施正文修订。

## 来源能承担什么

我没有打开原网页或刊物。依据资料读者的实际访问记录，[第三方转录页](https://dokumen.pub/structural-film-anthology.html)现已定位完整相关问答，页面显示Hartog署名；与MACBA目录的关联分歧仍未解决，原版排印和转录忠实性也未核验。不能继续说这段内容仅来自搜索片段，也不能升级为原版已核实。

转录所呈的回答反对提问前提，区分活动程度与价值，并使物件和事件之间的界线受到质疑。这是带真实性限制的作者话语，经资料读者转述后供我理解；不是普遍艺术法则。它并未讨论《背向房间》，不能替本作证明两类图像同等有力，更不能据此建立影响、优劣或新颖性。我采用它的方式，是让它质询自己的措辞，再回到已有作品依据检查。

## 被挑战的不只是一个词

A53的主要细读本来就没有把火与家具完全分开：第四节让红形和椅背共处，第六节承认同一情节可以吸收这些安排。但第四节标题“事件还在，物件已难指认”，以及“留下的形只能维持某种事件存在的指向”，仍容易把家具规定成提供具体空间的对象，把火规定成只剩事件提示的残余。后一句的“只能”尤其超过现有图证。

已有材料支持更复杂的关系。杯在24秒被近处画框截断、又由镜像保住；桌杯随后退出、椅背局部受遮挡，这些物件的图像同样参与了发生中的变化。火则不只有“发生了某事”的作用：60、84秒它与椅背的邻接及重叠构成具体位置关系。94秒仍有门框、墙脚、地面和一段火形；火形位于这些残余空间线索之中，不能被说成脱离空间的纯事件标志。它不能恢复已不见的杯柄或完整椅架，不等于它不能提供任何位置联系。

这里并非重新看片所得。本轮没有看新图，以上依据是此前直接看过的编码帧及已保存制作事实。火是否让正常观看者继续想到先前椅子的位置，仍需实际观看，不能用固定落位代为证明。但“94秒尚有可见空间线索”与“火形有自己的位置”已经足以限制旧文的排他推论，无须等待别人证实某种记忆。

## 愿意承担的修正内容

我仍愿保留家具与火在这件作品里承担不同作用的解释，但应把它写成这次安排产生的侧重，而非两种本体类别。具体可辨的家具结构退出之后，图像保留的是一部分火形及室内线索；可以追问哪些细节与位置联系失去、哪些仍在，不能概括成物件被事件完全替换。可见内容发生改变，也不自动形成从丰富到贫乏、从有价值到低价值的等级。

若后续实际修订论文，值得修改的是第四节标题与上述“只能”的句子，并检查“还看得见那里”与“还看得见那里的东西”的简称。火、门框和地面本身也属于那里可见的内容。新的表述须明确失去的是桌杯椅的特定交代，同时讨论剩余形状仍保有的有限位置关系；不能只在旧二分后面补一句免责声明。摘要和结尾随之限定范围即可，无须添加新的宏大论点或重述整套制作记录。

这比现稿已有“没有真实燃毁”“仍留室内线索”的事实限定多推进一步：它要求论证承认剩余图像仍能工作，不能只把剩余当作较少的具体性。我接受这种修正可能削弱原先整齐的递减叙述。火形与家具关系改变的作者取舍仍然存在，其艺术分量不能从分类纠正中自动增加。

A55提出的“向外位移仍经镜面指向室内”也应受到同样约束：镜面继续交代的内容具有多种作用，不能因位移与图像方向分开，就认定它维持了同等完整的空间认识。两项判断可以共同明确本作承担的范围；不由此建立与Snow实践的简单对立。

## 下一步范围

我的结论是值得一次有明确目标的论文论证修正，理由是收回现稿过强的排他推论，而非这份有限来源能够证明新贡献。来源在这里主要提供挑战；它仍不足以支撑确定的Snow实践比较，引用时必须连同第三方转录、原版未核验与署名分歧说明，不能借它为本作背书。
