# A48 作者规格：由后层承接的边缘缺损

2026-10-31。已全文读A47 DECISION与A48 BRIEF。此规格在任何新实现、运行和图像之前固定，落实A47的两张错层纸片选择；不授权运行，不是完成作品。工程者另做静态可行性；若不能落实，应先报告具体缺口。

## 拓扑修正与选择

这里准确称为“边缘缺损”，不称单张纸的内孔。初始受影响位置连接前片自身左边缘，但在两片组合的内部由完整后片承接。交换后，它仍连接接收纸片的自身左边缘，只是该处已在组合外露轮廓上。同一内孔不能因平移或旋转变成单张外缘缺口；本规格明确放弃这种表述。

因此，两阶段并非“前片上封闭的洞”与“后片上开放的洞”。我选择的关系是：同一份局部遮挡丧失，先使后片纹理从前片边缘露出，后使背景从后片外缘进入。前片恢复可能让整组反而显得不完整。这仍是预想，实际结果可以不成立。

## 画布、两片位置及外观

唯一作品画布为720×720像素，固定正视平面，不含文字、计数或按钮。坐标原点在画布左上，x向右、y向下。任何显示缩放须整体等比，不裁边、不改变两片相对位置。三张可能的检查原图均从这张原canvas导出。

| 项目 | 制作前固定值 |
| --- | --- |
| 背景 | 全幅不透明纯色 #1D2320 |
| 单片局部几何 | u从0到300，v从0到400的长方形；左上为(0,0) |
| 两片底色 | 同为 #E4DDCC，无照片、纹理噪声、阴影、厚边或光照渐变 |
| 三条线 | 同为 #4C514B；局部u=34、162、234；各宽2像素；均从v=20延伸到v=380；平直、无字 |
| 前片F | 中心(430,280)，旋转0°；左上(280,80)，右下(580,480) |
| 后片B | 中心(300,390)，绕自身中心在屏幕上逆时针旋转12° |
| 层次 | 背景最下、B其次、F最上；只有这两张纸片 |

局部坐标到画布的几何固定为：F的(u,v)对应(280+u,80+v)。B先把(u−150,v−200)绕原点逆时针旋转12°，再平移至(300,390)。这里按屏幕y向下定义：B的画布x为300+cos12°×(u−150)+sin12°×(v−200)，画布y为390−sin12°×(u−150)+cos12°×(v−200)。底色、线条和材料覆盖一起接受同一变换。不能只旋转纸框而不旋转缺损或线条。

纸片是本作自行构造的平面对象，不借用纸房、信件或私人遗物。两片没有一张被画得更旧、更暗或更珍贵。前后差别由固定遮挡位置给出。

## 对应材料与损坏位置

两片使用同一局部材料格：每格4×4局部像素，共75列、100行，材料中心为u=2+4i、v=2+4j，其中i为0至74、j为0至99。两片以同一(i,j)配对；不能按最近画布位置配对，不能独立重新采样。每格承载相应纸面和细线片段；边缘格覆盖到单片边界。格子是合成材料的呈现单位，不声称模拟了真实纸纤维。

前片唯一准备点火中心固定在局部(8,250)，局部命中半径36像素。工程者须静态核清其与原接口坐标及半径的等价关系；不能运行后移动命中位置。只允许F被直接点燃，B没有预损。最终可见缺损允许的局部范围W为u从0到96、v从205到295，并须实际接触u=0这条边。W是事前资格边界，不是把整块窗口切掉的形状指令，也不是事后裁掉越界结果的遮罩。实际缺损轮廓只由这一次材料准备得到。

这个范围在F上对应画布x=280至376、y=285至375，整体处于完整B内部；在B上的对应范围，其画布x约为154.3至266.9，全部在F的左侧边x=280之外。故前一处可以由B承接，后一处不会被恢复后的F遮住。这些只是由固定几何推得的范围，不是实际缺损图证。最终缺损若不接边、越出W或B已受损，均不把它重命名为计划成功。

## 局部遮挡的作者规则

此处“损坏”特指合成纸面局部失去遮挡能力。现有A42只有仍可读的字色变化与状态记录，没有证明原平台烧穿纸面；本作选择新的状态呈现规则，不能将它倒写成平台已有效果。

预定每格的覆盖不透明度为1减去限于0至1的char值；底色与该格内细线共同使用此不透明度。char为0时完全覆盖，char为1时不再覆盖，中间值如实半透明。位置、格面积、线宽和底色不随char、h、fuel、glow或state改变。h与glow不另生成纸面发光或热色；本画面不显示额外火团、烟、飞行碎屑、黑色补洞贴图或轮廓描边。正常画布边缘抗锯齿可以保留，不加额外模糊或美化。

这是一项事前规定的图像规则，不是新燃烧算法或真实纸燃烧验证。工程者应核实char语义及取值是否支持它；若不支持，记录静态缺口，不能运行后选择另一数组、阈值或映射来获得更漂亮缺口。若实施路径仅推进既有材料时钟、没有流体粒子，也必须如此记录。

## 观看、唯一动作与停止

准备遵守BRIEF的一次reset、一次点火和固定360步、dt为1/60；正常终点为第360步，不按画面好坏提前择帧或延长。错误可提前终止。原状仅作为三张记录中的第一张；普通观看从准备后的静止构图开始，准备成本仍完整记账。

画布外只有一次“恢复前片”动作和普通离开方式。观者可以在动作前后自行停留，无倒计时、自动循环或第二次转移。动作实际交换两片所有对应格的h、fuel、char、glow、state及必要前沿归属；精确工程合同由静态审计后另定。纸片与线条不动，动作不推进时间、不点火、不reset。交换后的可见差别直接来自交换后的材料状态，不用过渡动画代替这件事。

唯一艺术判别仍是：实际同一边缘缺损能否从“由后层承接、露出后片纹理”转为“在联合外缘露出背景”，让恢复前片与整组更破同时可辨。只出现淡色块、仅能凭记录识别同一性，或整体轮廓仍无可辨中断，都可以使这次关系不成立。工程交换正确不强制作者保留，更不启动论文。

## 作者对具体普通呈现路径的回应

2026-10-31，运行前追加。我接受root转述的这条路径仍是我的A48材料资格对象：新二维格片canvas直接读取原平台char数组，依本页的不透明度规则呈现两片纸面与细线。画面不是原Gaussian渲染。原平台在此只提供材料燃烧时钟与状态，不提供本作的纸面图像；原demo保持不改。我依据本次提供的静态核查结论作创作判断，没有另读源码或观看运行结果。

我接受elapsed材料时钟、spreadRate为0、关闭flame heat、scene feed与emitter，按burnT为6推进六秒的准备路径。这意味着缺损范围来自固定圆形命中集合与4像素格，不是燃烧传播发现了一种新轮廓；六秒也没有被选为需要观者经历的作品节奏。没有流体粒子或真实纸燃烧主张。此项收窄现在确定，不能在图后把规则产生的缺口写成不可预见的火形。

这一限制没有撤去我所选的关系：被交换的是对应材料状态，变化发生在两份纸面自身；同一边缘缺损先由后片承接，后在组合外缘露出背景。作品不需要证明Gaussian绘制或燃烧时钟不可替代。与此同时，固定命中与普通格片绘制使“一个缺口换位”的反读更直接，我接受它，不用材料来源的复杂程度增加分量。
