# A14《两边的火》制作说明

2026-10-30。依据本目录 PROPOSAL.md 与 CONTEXT.md 的一次有限实现。此文记录制作选择，不是实际观看结果、独立评分或合格声明。根页面 `index.html` 为仓库内本地作品；没有新建或部署外部网站。

## 场景与形状

所有点由页面内确定性程序新建，编码为内存中的 `binary_little_endian` 3DGS PLY，经原 demo 的 `loadPLY` 载入。无远程素材、旧场景重剪、磁盘大资产或随机几何采样。14 个 float 属性为 x/y/z、f_dc_0..2、opacity、scale_0..2、rot_0..3，每点56字节。无高阶SH。

- 地面是3.8×3.8单位的深灰绿正方形。炉的底面1.18×1.18，高至1.075；炉底0.15。负x与负z两墙围起同一腔体，正z与正x两口互成90°。正面窄门柱、横梁和暖色口沿保留开口；顶部为开冠环，中央没有隔墙，没有第二个火箱。
- 两块地垫完全同形同色、同一采样织纹，宽0.84、深0.74。A垫中心为(0, .035, 1.40)，B垫为其绕竖直轴旋转90°的位置(1.40, .035, 0)，距炉心相同。
- 中央六根交叉短木段构成一个火床：单根长0.62、截面半径0.038，两层中心高度0.235与0.305。唯一点火位置为(0, .29, 0)，半径.30。点燃数若为零即错误停止，不移动火源补救。
- 表面由各向同性高斯采样，按代码网格推算为5381点；初始化时计算并公开于 `snapshot().pointCount`，代码硬上限8000。各几何组计数也保留于该接口。点位先转Float32，再计算均值，以公开场景偏移补偿 `loadPLY` 的自动居中；`sceneScale=1`，保留上述作者坐标。

炉形、地垫及木段是合成呈示形状，不含分别标定的金属、织物或耐火材料模型。它们不证明真实燃烧、实际冷暖或座位间的热量分配。

## 固定推进与观看时间谱

`seed=20261030`；全9层VPM，每层容量160；`dimMode=layer`、`sliceMode=view`；`dt=1/30`，每次仅一步，总计360步。两种热反馈开启，基础emitter关闭，legacy clock / block particle policy / legacy measure。`spreadOn`在唯一点火之后开启。未另调传播半径、传播速率、燃烧时间或准入额度。

显示参数固定为`exposure=1`、`bloom=.65`、`sceneLight=1.1`，SH0，其余未列参数继承原demo默认。仿真机位距离3.6、仰角.18；yaw以π为单位。来源画布固定640×480，两块呈示画布也各640×480、始终等大；窄屏仍并列，保留两个位置的同时性。

1. **开始前**：一张共同远景，yaw=.25、距离5.6、仰角.41，能交代共腔炉与两地垫。只render，不reset、step或ignite。按「开始观看」才reset一次、点火一次，打开等大的双画面。
2. **0—6模拟秒，步1—180**：A为推进机位，从yaw0缓慢侧移至.10；B停在.50，只观察。移动为`smoothstep(t)=t²(3−2t)`，两端缓停。
3. **第180步后交接**：先保存完整公开导出，再将推进机位改成B，再保存导出。不增加一步，不reset、不重新点火。逐字段JSON比较只排除`params.yaw`；不一致即停止。接口保留前后概要与比较结果，不输出逐点大数组。
4. **6—12模拟秒，步181—360**：B从yaw.50缓慢侧移至.40；A留在.10继续观察。B接手此前计算状态。
5. **360步后**：停止物理推进。两个机位都在2.2墙钟秒内退至距离5.6、仰角.41，各保持自己的yaw；保留等大双远景，没有单个“正确正面”。火停在第360步状态。检查模式直接呈示这一后退终点，不额外推进或延长火的演变。

正常播放每帧最多推进一步，无落后追赶或效果导向加时。页面分别显示模拟时间与从开始起经过的墙钟时间（包含暂停）；两者不保证相等。可暂停/继续；结束后「重新开始（重新初始化）」会从同一个固定seed开启新的序列，明确意味着再次reset与点火，不自动循环。

## 一份状态与两种呈示

仅一个同源iframe载入原demo：`?embed=1&solver=vpm&orbit=0`。其RAF在embed模式不自主step或render；页面不发送tick消息。每一步先显式恢复推进机位的yaw、距离与仰角，然后调用`research.step(1,dt)`。

每次推进之后，对A、B依次设置观察机位、调用原`render`、`gl.finish`，并在同一JavaScript调用栈内用2D `drawImage`立即复制来源画布。两次复制之间没有新step，也不等待RAF。`finally`恢复推进机位，下一步前再次恢复，防止第二次观察的yaw进入下一步。结尾后退也是两次真实render，而非对既有图片缩放或伪造视差。

分层view火焰的映射本身随机位改变；这两幅图是**同一计算状态的两种呈示**，不等同于固定三维火体的纯机位绕拍。没有把视觉差异直接称作烧痕、热量份额、观众感受或艺术贡献。字幕交代规则及时间，不替两边裁定所得。

## 检查接口及边界

`window.__a14`为冻结接口对象：

- `ready`：初始静态对象完成render后resolve的Promise；初始化失败时reject。
- `snapshot()`：新的JSON副本，含phase、frame、simSeconds、driver、driverYaw、params、pointCount、累计ignitionCalls/resetCalls、lastHandoffBefore/After概要、handoffEqualExceptYaw、errors、实际经过时间、场景组计数与最近一次物理概要。读取不推进、不重置。
- `inspectAdvance(n)`：仅在`?inspect=1`有效，调用与正常播放相同的`advanceOne`及双render/copy函数。必须先按开始；暂停时不得推进；不接受超过本序列剩余步数的请求。该query阻止页面自主RAF推进。每6个显式步骤让出事件循环，允许外部await；不会启动隐藏效果试验。

检查计划由root固定为一次有界实际观看；本实现阶段未运行浏览器或仿真。错误显示并保留当前图，停止推进，不自动重试。结束按钮可以被检查，但本次核验不为追求效果开启第二序列。无localStorage、个人资料、遥测或外网请求。已使用Sites技能中与本地buildless HTML有关的制作指引；注册、同步、部署及托管流程均不在本任务范围。
