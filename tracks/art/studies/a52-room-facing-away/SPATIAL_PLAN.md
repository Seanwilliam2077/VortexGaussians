# A52《背向房间》固定空间与渲染实现

2026-10-31。实现前全文阅读 A51 `CREATOR_PROPOSAL.md` 与本目录 `BRIEF.md`。本文件记录一版已经固定的实现关系，不把解析投影、源码检查当作实际观看。Renderer 工程 Agent 未开浏览器、运行火源、截图或编码；实际材料与原作者取舍由 root 后续有限制作完成。

## 同一空间

单位为任意米尺度，y 向上。屋内 x 为 −3.4…3.4、z 为 −6.2…0，高 3.2。门洞位于 z=0、x=−1.3…1.5、高 2.65；门扇向室内打开，真实网格仍参与遮挡。走廊在正 z 方向，随后沿正 x 方向延伸，在 x=2.5…4.5 的范围折向正 z。灰窗在房间左墙 x≈−3.36；窗面没有外景图片。

桌面中心 (0.7, 0.8675, −2.6)，尺寸 (1.8, 0.065, 1.4)，桌面顶 y=0.9。桌沿有深色细边。白杯底中心 (0.03, 0.9, −3.09)，半径 0.115、高 0.22；杯内壁、口沿和杯柄都是网格。柄沿平面方向 (−0.76, 0, 0.65) 朝向椅子。折椅中心约 (−0.66, 0.5, −2.55)，朝正 x；交叉椅腿、椅背上缘和独立横撑均为几何，不能通过火参数删掉。

窄镜中心 (0, 1.605, 3.5)，宽 1.35、高 2.05。它所在墙面沿 y 轴转 12°，水平单位轴 u=(cos12°,0,sin12°)，朝走廊的法线 n=(sin12°,0,−cos12°)。背墙位于镜面后 0.026 的距离；镜框也是真实几何。镜面并非悬空屏幕，而是对面墙的一小段固定斜面。镜子、桌椅、门、源粒子只有一套世界坐标。

## 相机与两分钟

眼高恒为 1.62，垂直视场 48°，16:9，近远裁面 0.045/40。`scene.mjs` 的 `CAMERA_KEYS` 是全部固定控制点；各维用共享导数的分段三次 Hermite 插值，因此位置和朝向一阶连续。输入时间不会改变路线、相机目标或图像取舍。

0—24秒，从桌右侧 (2.55,1.62,−4.90) 向前侧移，白杯、桌边、椅背与灰窗共同构成房间；出口在画面侧方。20—30秒朝向逐渐转向门，使桌的一部分直接视野与同一桌角的反射短暂相接。24—46秒沿桌右侧、门扇左侧走出门，46秒位置 (0.40,1.62,1.00)。经过门口的转弯后，相机在50—94秒以约0.045世界单位/秒沿正 x 前行，镜中形体逐渐被物理镜边裁掉；并不因截图或具体物件的识别状况停步。84—104秒继续右移并转入普通走廊转角，镜面离开视野。104—120秒保持同一环境亮度，继续到 (3.15,1.62,3.25)，没有再次看到房间或灰烬。

## 反射与遮挡

WebGL 1，未引入第三方库或资产。先画主场景的深度，再将镜面真实可见的像素写入 stencil。只在该 stencil 区域把深度重置到远平面。反射矩阵为 R(p)=p−2n(n·p+d)，d=−n·镜面中心；以同一透视投影和 `view * R` 重画同一个 world buffer 一次。反射时裁掉镜面背后的原世界几何，避免背墙覆盖镜像。门洞两侧、门扇、桌椅仍正常参与该次深度测试。反射不是离屏视频，也不是镜中另造一间房。

粒子同样通过 `view * R` 绘制，按本视图深度从后往前排序，接受不透明几何深度遮挡；再以轻微银灰覆盖恢复镜面表面深度。主画面也使用同一组粒子，只是46秒之后室内位于相机身后。只有一次平面反射，不递归反射，不声明多次光输运。

已做的解析检查仅为固定坐标计算：24秒白杯中心的反射射线打在镜面 u≈−0.473、v≈−0.310，位于半宽0.675/半高1.025以内；从相机到镜面、从镜面到杯的两段射线穿过 z=0 时 x 分别约0.752与−0.205，均在门洞内。60秒杯中心 u≈−0.025，椅背中心 u≈−0.324；84秒杯中心 u≈0.733，越过右镜边。这个计算只说明位置接续与裁切可能，不替代完整几何遮挡、实际像素或可辨认性的观看。源码已通过两项 `node --check`；没有用浏览器编译器预跑GLSL。

## 原火源的固定图像映射

调用独立模块 `createFireSource()`，`read()` 直接取原派生源的有限粒子数组 `{x,y,z,temperature,density,radius}`，不改源模拟。影片时间 t 的源时间为 clamp(t−46,0,58)，同步推进、每步1/24秒；原温度字段是色温强度 p.T，非 Kelvin，也不是浮力温度 p.Tb。

每粒子世界位置严格固定为 `(0.18+0.62*x, 0.90+0.70*y, −2.12+0.62*z)`；原9层的 z 已在源模块映射到 ±0.35，这里只统一缩放。喷口位于桌远侧靠左部分。点半径为 `0.70*radius`，使用普通软点精灵、预乘透明混合，最大点径72像素。前3秒只做显现淡入，没有修改粒子位置或从其他火视频插入画面。根据源原有温度与密度染色；不额外造烟、烧毁贴图或移动家具。

房间材质使用作者固定的环境光、窗侧方向光与温暖局部点光。火光以14秒平滑增长到固定强度，再用两条小幅正弦变化，位置 (0.18,1.24,−2.12)，距离4.1外为零。该光照与接触暗部是常规艺术化着色，不是原火物理或真实遮光求解。火形与透明叠加可以改变桌椅可见性，家具没有物理燃毁、拓扑变化或被删除。

## 页面与调用

`canvas#view` 固定1280×720；canvas内没有文字、分屏、音效或操作界面。页面外提供播放、暂停、离开；初次就绪画t=0但不自动播放，影片在隐藏页面时暂停。一个页面只前进；普通重看需要重新打开页面，不提供作品内部的回退结局。`?embed=1` 隐藏外部控制。

`window.__a52.ready` 是准备完成 Promise。`renderAt(seconds)` 同步、拒绝倒退或范围外输入，返回小型本帧相机/粒子/源时间状态。`inspect()` 汇总来源、空间和成本，不返回大型粒子状态；`dispose()` 释放GL资源与源iframe。播放和离线调用共享同一个时间接口。
