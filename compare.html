Grid Mode vs Grid-Free — the same fire, two solvers

Both sides run the same seed, the same fixed timestep (1/60 s), the same particle budget and renderer, stepped in lockstep — the only difference is how velocity is computed. Grid Mode deposits vorticity on a 32×48 grid per slice and solves a Poisson equation; Grid-Free evaluates each rendered splat as a Lamb–Oseen vortex element through a treecode — no grid anywhere.
